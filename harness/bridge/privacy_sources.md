# 上传前本机脱敏：来源与边界

本模块复用本项目 `reader.py`、`store.py` 和已安装旧项目的 `cn_contract.documents` 读取器及 RapidOCR 本地 ONNX OCR。26 种扩展名采用同一条现有解析路径；PDF 遍历所有页，图像页与有图片的 PDF 页仍执行本机 OCR。只把提取文字送入规则替换，生成全新的 UTF-8 TXT，不上传原 Office/PDF/图片容器或隐藏部件。

规则与隔离设计参考用户提供的立丰脱敏 v2.7 静态评估，以及 ZIP 中 `engine/desensitize.py` 的类别及边界处理思路。ZIP SHA-256 为 `922d152819f8e3b361817a9c3e1878e0f26c5a844adbe3d79b2121089c1c7cec`，详见 `.local/package-assessment/desensitize/report.md`。未复制该包的业务代码、规则库或运行时；其无明确复用许可、导入全局副作用、Mac OCR 与私有目录依赖使直接集成不适合本次范围。当前规则在本项目独立实现，既有读取/OCR模块直接复用，没有引入新的依赖。

支持的自动识别为常见大陆移动电话、带分隔符座机、邮箱、身份证、统一社会信用代码、带标签账号/护照、部分可校验银行卡、带明确姓名标签/称谓的人名、常见组织后缀、带地址标签或街道门牌的地址。不是通用命名实体识别，也不能自动覆盖所有外籍姓名、别名、无上下文姓名、境外证件、拆行/错字和间接识别信息。自定义敏感词按字面识别、Unicode NFC 统一、重叠时优先最长项；一次替换防止生成代号再次被替换。金额日期不设自动替换规则，但明确自定义词可以覆盖用户指定内容。

2026-11-13 补充两种有界语境：句子或标点边界后的常见姓氏姓名“已签收材料/文件”等，以及“姓名将……转交给姓名”。只在这些语境中筛除常见普通词、星期和角色称呼，不按任意二至四字汉字推测姓名；明确姓名标签和已经确认的上下文映射不被这组语境排除词撤销。称谓识别仍限制二至四字，不把相连的“感谢”“会见”等动词扩入姓名。其他未覆盖的叙述仍需自定义词或人工复核。

OCR 空白处理保留匹配到的原始字符。明确标签/称谓中的短姓名允许有界空格；没有既有字典时，换行只自动合并二至三字姓名主体后的最后一个单字，并拒绝下一行的“字段名：”及多字正文。下一行以“一、”“二.”等条款编号开头时，不将编号拼入姓名，既有字典也遵守此边界；姓名末字后的普通逗号仍可识别。组织识别允许现有公司等后缀内部的一次换行或有界空格，不把任意相邻两行拼成组织。已经确认的人名/组织可在同一显式 `context_id` 中识别一次换行或有界空格变体；不同原始写法分配不同代号，因此恢复所选代号能精确保留其原来的空格或换行。相同原始写法沿用原代号，不重写旧映射。此处的逐字恢复针对提取文字，不恢复解析器已经省略的版式或图像。

默认每份文档独立映射；只有调用方显式提供同一个 `context_id` 才复用代号。SQLite 事务串行同一上下文的映射分配。调用方必须使 `context_id` 绑定一个案件/批次，跨案件不能复用。全部原件、包含原文的解析索引、原路径清单及映射保存在独立 vault；接口不返回原值、原名或映射。仅成功结果的 `safe_path` 可复制到模型工作区。Node 上传入口负责确保暂存、vault 不在任何模型可访问目录内，并只接收 `status=ready`。

`workspace_dir` 为传入的模型工作区，Python 额外拒绝 vault 与其相交；未传时只检查本项目默认 `workspace`，不能代替上传端的实际路径校验。固定错误不会回显异常中的原文/路径；解析失败或整份无可读文字不提供原文降级。部分无法提取的页/嵌入对象不进入文字副本，固定提示明确说明其缺失。OCR/识别有误差，准备成功仅表示此文字转换和规则替换完成，不表示完全匿名、原版排版保留或能恢复已省略图像。

私有 vault 为本机明文文件，继承本机目录权限，不宣称加密。没有接入全局词表学习、模型识敏、外部网络服务、批注恢复或向原文回填；这些不属于本次上传前文字副本能力。
