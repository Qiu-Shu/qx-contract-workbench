## 安装与使用

双击安装包即可按当前Windows用户安装，不需要另装Node或Python。桌面与窗口名称为“群兴法律工作台”。首次启动填写自己的DeepSeek API Key，点击“验证并进入工作台”；以后在“工作台 → API设置”更换。微信入口位于左下角DeepSeek余额上方，打开后由用户本人扫码。

## 本版包含

- 首次API引导、Windows加密保存、微信连接弹窗及余额入口。
- 本机律所知识库、图片导入与可选上传前脱敏。
- 合同默认批注，保留正文；明确要求修订时才改正文。意见书同时生成HTML和Word。
- 模型失败请求自动恢复，保留前面已完成的工具结果；新增异常参数和断流恢复，沿用normal策略最多5次重试和默认退避。认证/额度错误不盲重试，持续失败会保留已有成果并停止。

## 资料与边界

用户资料和加密设置位于 `%APPDATA%/QunxingHarness`，与程序目录分开。关闭窗口后微信后台继续运行；升级和卸载只停止本安装实例，卸载保留资料。安装包不含开发机用户材料、微信登录态、API Key或脱敏映射。

未使用商业代码签名，Windows可能提示未知发布者。尚未在另一台干净电脑上验收。微信需本人扫码；bb-browser连接需用户自己的浏览器扩展；外部打开Word需已有WPS或Office。模型请求重试不等于任意外部工具或断电后的全局不重复执行保证。
