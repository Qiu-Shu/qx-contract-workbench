# 新会话四大能力卡片

在新会话“AI师兄法律助手平台”标题和输入框之间，通过官方 `conversation.input.dock` 插槽加入四张能力卡片：客户接待、合同审查、办案整理、模拟法庭。沿用既有灰白蓝配色、字体及布局，不更换标题或品牌。

卡片悬停上浮 5px 并放大至 1.035 倍，移开时使用弹性曲线回到原位，按下时轻压。此弹性为用户明确要求。窄容器自动改为两列；减少动画偏好下取消位移与缩放，保留颜色/阴影反馈。卡片只在新会话页面展示。

点击后调用官方 `inputActions.captureInsertion/insertText`，把对应提示词放在当前草稿末尾并聚焦输入框。不自动发送、不覆盖选中的原文、不移除附件；可撤销，重复点击同一未修改提示词不重复追加。刷新后由原有草稿存储恢复。没有工作区导致输入框未就绪时，提示先选择工作区。

每个提示词用自然语言引导对应现有业务，并留出用户补充位置，不向用户展示工具名或案件编号。四能力的后台规则和材料工具未修改。
