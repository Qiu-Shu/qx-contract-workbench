# 0.2.5 启动恢复修复

0.2.4 在已经保存 API Key 的情况下，如果后台首次启动超时或连接失败，会错误打开 API 配置页。密钥本身没有丢失；本版将这种失败转入现有恢复页面，继续使用原有加密配置，后台恢复后可重新连接。真正首次安装仍要求配置自己的 API Key。

同时合入界面加载状态：打开期间显示加载提示，前端根节点长期为空或后来被清空时提供重新连接入口。记录经过筛选的错误类型和加载状态，日志不记录异常正文、密钥或客户材料。不自动重发对话或刷新草稿。具体范围见[白屏排查记录](2026-11-04-白屏排查与加载恢复.md)。

本版包含 0.2.4 的生成文档与上传附件预览、标准/深度脱敏、后台恢复和技能名称修复。既有资料目录、加密密钥位置、更新签名身份及更新缓存名称均不变。

## 安装与更新

[正式发布页](https://github.com/Qiu-Shu/qx-contract-workbench/releases/tag/v0.2.5)。0.2.3 及后续版本使用律所知识库上方黄色升级按钮增量下载；也可从“工作台 → 检查更新”触发检查。旧版本继续可用。缓存丢失、网络不支持 Range 或校验失败时停止更新，不自动下载整包。

新用户及 0.2.2 或更早版本需手动安装 `Qunxing-Workbench-0.2.5-Setup.exe`。已有用户无需重新填写 API Key；安装前保存内容、结束正在执行的任务。历史 Release 与 blockmap 保留。
