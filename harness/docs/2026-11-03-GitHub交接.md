## 已完成的用户要求

当前版本包含简洁桌面聊天、文件拖拽和粘贴、群兴文字标识、余额、微信收发及连续消息合并、按需法律 Skill、上下文压缩、文档和图片读取、上传可选脱敏及本机律所知识库。

接待的客户回复与内部分析分开保存；合同读取附件、保存意见并生成 Word；办案持续整理时间线、证据缺口和待办，更正保留原记录；模拟法庭五阶段、11 次发言逐条保存并可回读续接。合同修改默认批注，正文保留；意见书采用分节和四列风险表，生成同内容 HTML 与 Word。

自动恢复复用官方 `llm-deepseek` 的 `retryPolicy`，normal 模式最多 5 次重试，覆盖 EMPTY_RESPONSE、RATE_LIMIT、SERVER、TIMEOUT、TRANSPORT、MALFORMED_RESPONSE、STREAM_CLOSED。失败的模型请求在同一步恢复，前面成功工具的结果与文件不重放；失败尝试保留。停止、认证及余额错误按原机制处理。没有增加业务回答字段/长度校验门禁。

## 继续工作的位置

文档工具在 `bridge/`，业务留档在 `bridge/business_store.py`，合同 Skill 在 `config/skills/qx-contract-review/`；桌面集成在 `desktop/`，微信在 `plugins/wechat/`。模型恢复设置在 `config/cordis.patch.yml`；安装迁移在 `desktop/installed-migrations.cjs`；构建入口在 `packaging/`。

当前开发构建仍复用本机路径和已安装依赖；新电脑使用 Release 安装包。源码迁移时先按 [构建说明](../packaging/README.md) 准备依赖并调整路径，不要删除旧开发目录或覆盖用户工作区。安装版自带运行环境，资料位于 `%APPDATA%/QunxingHarness`。

本次公开同步只包含程序、公开上游材料、许可证和合成验证记录，不含运行工作区、API Key、微信登录态、私有映射或客户原件。公开记录中的 `.local/` 证据路径仅用于本机追溯，不承诺可从 GitHub 下载。
