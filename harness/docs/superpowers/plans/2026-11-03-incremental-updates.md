# 群兴增量更新实施计划

> 使用 executing-plans 在当前会话逐项实施；使用测试驱动与完成前验证。

**Goal:** GitHub Releases 增量更新；知识库上方黄色升级按钮；不强制升级。
**Architecture:** Electron 主进程使用 electron-updater NSIS 差分下载；主进程验证签名，受限 IPC 向现有侧栏提供状态和操作。后台检查不弹窗，用户展开小面板后下载、确认安装。
**Tech Stack:** Electron 44.8.0 / electron-builder 26.15.3 / electron-updater 6.8.11 / Node crypto / 现有 React 客户端插件。
**Spec:** 本会话用户明确要求：增量下载而非整包、黄色按钮位于律所知识库上方、不全屏提示、旧版正常使用；最新决定先尝试 GitHub，保留 OSS 切换配置。

## Global Constraints
- 禁止差分失败后静默下载整包；首次安装包仍需提供给新用户。
- 不强制升级、不设置过期锁定；检查/下载失败不影响原有工作。
- 安装前明确提醒保存并结束工作，安全停掉本安装实例后台；停止失败禁止安装。
- 更新不得覆盖用户材料、API Key、微信状态和自定义设置。
- 更新元数据 Ed25519 签名，SHA-512 校验最终安装器；私钥不打包、不进 Git。
- 本次先构建与本机验证；公开发布另需用户明确授权。

## Review Focus
- 差分错误/缓存缺失不得触发完整下载。
- 签名错误、版本倒退、远程说明含 HTML 不得执行。
- 重复点击和下载取消不得造成并行安装或状态倒退。
- 停后台失败、正在设置密钥时不得安装。
- 老运行环境无更新桥时侧栏保持原样可用。
