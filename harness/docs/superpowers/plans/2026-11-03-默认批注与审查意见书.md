# 默认批注与审查意见书

用户明确指定合同修改默认批注，并认可其提供HTML的排版。目标是让合同正文保留、意见易读且能用于谈判。此次不重新出具该真实学校合同的法律结论，因为只提供了既有意见书，没有原合同。

实施：

- `write_review_docx` 与MCP `write_review_word` 默认comments；建议替换/删除文本放入批注。明确指定tracked_changes时保留原修订功能。
- 依据参考版式建立意见书工具，共用内容生成HTML与Word；文件同名另存，不复制客户事实、旧日期或检查声明。
- 合同Skill与工作区规则同步，强调原文—后果—行动、优先级依据、有利条款、未明商业事实分支及可执行谈判条款。
- 使用合成资料测试默认正文不变、原批注/修订保留、显式修订兼容、HTML文本转义、同名另存、长段和表格、真实stdio接口及Word渲染。

不改变上传脱敏、微信、知识库和安装器。安装会话已知本轮属于上一冻结版后的修订，不混入正在压缩的0.2.0版本。
