# 业务闭环与上传前可选脱敏

用户已明确要求实施。保留现有桌面、微信、模型选择与输入流程；不新增内容格式或审批门禁。

## 方案

- 接待的内部底稿和可转发回复一次事务分开保存；客户导出只选客户记录。
- 案件更正追加历史，过期更正返回当前编号，避免多个“当前”；已解析附件建立版本文字快照。
- 庭审逐条保存，并可按案找到未完成演练、分页回读全文后从下一角色继续。
- 文档使用独立工具生成无覆盖 Word、原文修订批注及干净的诉状/证据模板；不移植分发包的私有审批框架。
- 上传前默认不脱敏，用户勾选后本机解析/OCR生成脱敏文字副本。原件、映射、临时解析索引存于工作区外的本机私有目录；处理失败不递交原件。文字副本不保留原图和版式，不能承诺自动识别所有身份线索。
- 文件选择、拖拽、粘贴和知识库上传共用独立前端处理；ZIP备份恢复不拦截。界面只加开关、可选自定义敏感词及处理状态。
