# 劳动合同审查 Skill 接续

目标：沿 0.2.19 已有来源绑定接口补全劳动审查候选流程，不增加工作台、首用问卷或重复输入。原基线 bf22aa936575b52fb227766cdba880f98ce4314b；独立分支 codex/employment-review。

范围及约束：合成材料、离线真实工具测试和代理应用测试；不调用产品收费模型，不读取真实案件，不改变已安装程序。完整专项继续保留 withheld，直到另行完成已明确模型与预算的质量评测及法律复核。候选放在 evals/candidates，不能仅改开放清单冒充修复。

1. 基线：仅使用现有 qx-employment-checklist 应对五类合成请求，保存原始回答与环境限制。重点是完整流程缺失，不能将未提供工具记作代码失败。
2. 先验证试用工资四项金额的人员、记录及期间对应关系。真实 CaseStore/解析/保存测试先失败，再复用已有参数提取与关联判断修复；保留正常同源核算，局部待核不丢其他意见。
3. 编写 qx-employment-review 候选及按需法源参考：材料覆盖、事实/法律分栏、录用/变更/解除/争议、工资表与合同关联、附条件候选条款、保存回读导出。复用 assess_employment_terms、assess_employment_termination、save_employment_review 及受保护交付。
4. 冻结合成场景及评分规则，新上下文应用候选；检查是否形成可做的业务意见而非全面拒绝，工具缺失时保持未执行。工具链另用实际 MCP/Word 验证。
5. 目标回归、完整 offline、两轴独立审阅；记录命令、退出码、真实数量及未测范围。更新本次接续记录和旧接续清单，提交当前分支。

审阅重点：工资同片段跨人/跨时期拼接；已约定竞业补偿误套30%自动补差；未知当不存在；合同摘录冒充附件全覆盖；引用匹配冒充事实认证；聊天和 Word 不同稿；候选意外进入运行载荷。

完成边界：本轮交付为有证据的候选与工程修复。真实应用模型质量、律师验收、入口开放和新安装包另列，未运行不得标通过。
