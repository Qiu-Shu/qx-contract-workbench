# 0.2.7 发布交接

本版只启用已通过对应难例和实际工具复测的新证据分析 Skill。当前共 186 个入口，150 个可自动调用，36 个旧入口保持停用。劳动用工、诉讼起草、公司治理、企业合规、知识产权台账五个新增专项 Skill 仍待复核，暂不进入可调用目录；合同 SaaS 与指引扩展也未纳入本版。

保留经过针对性验证的底层文书、引用、案件隔离和精确情景计算工具。引用匹配不代表事实属实，算术结果不代表法律应付，生成的法律分析和文书仍须承办律师复核。本次代表性工具验证不能证明所有复杂法律题均已通过。

首次安装可选择目录；已有 0.2.6 程序在基线匹配时可进行增量安装。升级保留用户资料与账号设置。正式附件为安装程序、blockmap、latest.yml 与 SHA256SUMS.txt；发布过程中先校验草稿附件，再开放正式版本。

公开源码位于仓库 `harness/`，沿用 `codex/skill-integration-checkpoint-20261102` 分支。部分既有打包及验收脚本仍使用开发机固定工具路径，重建前须按本机实际 Node、Python、7-Zip 和工具目录配置；此为已知重建局限，未为本轮发布改造构建系统。

公开源码不包含本机工作区、客户材料、账号凭据、私钥、原始模型日志或内部评阅数据。法律库规则种子按既有打包来源处理；不将用户知识库整体上传。旧发布版本、旧记录及开发验证历史均保留。
