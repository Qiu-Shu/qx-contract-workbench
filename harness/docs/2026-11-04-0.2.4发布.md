# 0.2.4 预览与脱敏更新

本版将文档预览修复、两种上传前脱敏方式，以及此前已在本机验证的后台恢复和技能中文名称更新合并发布。

- 生成的 Word 等 Office 文件可在右侧预览，安装包携带 Windows 本地转换引擎。
- 上传完成的文件卡、历史消息中的上传文件卡可点击预览；保留删除、失败重试和图片大图预览。预览不改原文件。
- 标准脱敏补齐品牌、产品、模型名和备案编号等识别；深度脱敏额外隐藏识别到的资质、荣誉与覆盖规模等事实。修复通用词误遮、历史映射影响后续处理的问题。脱敏后上传的是文字副本，原件保留；自动识别仍可能遗漏。
- 保留后台有限次数自恢复、断线提示、退出日志、技能中文名及默认辅助 Skill 修复。

## 用户升级

正式版本入口：[v0.2.4](https://github.com/Qiu-Shu/qx-contract-workbench/releases/tag/v0.2.4)。

0.2.3 用户启动工作台后自动检查更新，也可用菜单“检查更新”。新版本在律所知识库上方显示黄色升级按钮；点击下载变化部分，完成后选择安装。需要保留旧安装器缓存和历史版本 blockmap，缺失或网络不支持 Range 时停止更新，不自动转为下载整包，也不限制旧版使用。

0.2.2 及更早版本没有更新模块，需手动安装一次 `Qunxing-Workbench-0.2.4-Setup.exe`。首次安装仍使用完整安装包。升级保留 `%APPDATA%/QunxingHarness` 内的资料、自定义配置和微信连接资料。

发布资产包括安装器、`.blockmap`、签名 `latest.yml` 和 `SHA256SUMS.txt`。沿用原 Ed25519 更新公钥，完整上传并核验后再将草稿设为最新正式版本；不覆盖历史版本。Windows 商业代码签名与更新清单签名不同，本安装器尚无商业代码签名。

## 验证范围

本轮发布前重新运行 66 项桌面测试、12 组脱敏接口检查、154 项 Python 测试及 21 项子测试、3 项打包测试，全部通过。此前已通过独立真实工作台的生成文档、发送前/历史附件、Word/Excel/PPT/PDF/文本和图片预览；脱敏的两种方式、文件选择/拖入/粘贴及文字/Word/图片 OCR 链路见[脱敏交接](2026-11-04-脱敏增强与两种模式.md)。

最终安装包的签名、源文件一致性、预览引擎完整清单、首次配置及后台启动均已核验。黄色按钮位置、取消下载、稍后安装和旧环境兼容也已通过界面检查。

0.2.3 至 0.2.4 的正式安装器经 20 个本机 HTTP Range 请求成功重建，下载变化数据 56,747,841 字节（约 54.1 MiB），复用 555,447,500 字节，完整安装器 612,195,341 字节（约 583.8 MiB），节省 90.73%。重建文件通过原发布公钥验签和完整 SHA-512 校验；以上流量不含少量更新元数据。见[发布前验收报告](checks/release-0.2.4/report.json)。

公开 GitHub 文件摘要和真实客户端更新发现将在发布后再次核验。本机直连结果不代表所有大陆地区、运营商或时段；尚未在另一台干净电脑验收。

本次不包含账户注册登录或神经网络模型接入。源码工作区与发布仓库的 `harness/` 对应；客户资料、凭据、映射和本机运行记录不上传。
