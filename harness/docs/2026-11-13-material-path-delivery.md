## 问题与修复

上一轮发现的 252 字符索引路径可以创建数据库本体，却不能建立 SQLite 事务日志；因此材料后台在初始化时退出。同位置、同权限的对照实验中，119 字符普通路径可用，252/310 字符普通路径失败；Windows 扩展路径在三组长度和中英文、空格、`#`、`%` 目录下均可完成实际事务。

现在只在已校验路径交给 SQLite 时采用 Windows 扩展表示。材料索引、共用索引的案件数据及私有脱敏映射使用同一转换，工作区根、相对材料键、输出路径及数据库位置不变，继续保留事务日志、WAL、回滚和原有链接/越界检查。非 Windows 分支直接使用原路径，没有修改数据库格式或搬移旧库。

公开脱敏流程另暴露出复核记录文件名超长：数据库修复后，263/278 字符的复核 JSON 写入仍失败。对这个已校验、随机生成文件名的写入同样采用扩展表示，确认结果仍返回普通安全副本路径。
