已知员工2019年入职，目前每月到手11000元。主要核查如下：

1. 先确认解除路径。“N+1”通常涉及单位依特定法定事由解除、以一个月工资代替提前30日书面通知，并非所有离职均适用。协商解除需看提出方及协议；违法解除可能涉及继续履行或赔偿金，不能统一套用N+1。
2. N取决于实际入职日、解除日及应计入的连续工龄。经济补偿通常每满一年计一个月；满六个月不满一年按一年，不满六个月计半个月。历史工龄承接、此前补偿等安排需要核对。
3. 到手11000元不能直接作为计算基数。经济补偿通常依据解除前12个月应得工资平均额，还需核查奖金等工资项目及法定封顶条件；适用代通知金时，其基数通常为上一个月工资标准，两者可能不同。

暂列计算式：经济补偿＝核定N×核定月工资基数；如依法适用另付代通知金，再加其核定金额。仅当两个工资基数均经核实为11000元且确实适用时，才可表示为11000×（N＋1）元，仍不是最终结算额。

补充核验清单：具体入职及拟解除日期、解除事由与提出方、通知及送达时间、解除前12个月应发工资明细、上月工资标准、工龄承接或已获补偿记录。现有信息无需重填；收到这些材料后再核定金额，并按实际收到的附件逐项记录审阅范围。
