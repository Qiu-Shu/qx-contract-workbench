不能直接认定应按工资30%补差，也不能据“未到账”的单方说法认定现在即可停履行。你可以先按以下方案推进。

1. **补偿金额**：已有每月2000元的约定，12000×30%=3600元并不当然成为应付额；30%标准通常针对未约定离职后竞业补偿的情形。每月1600元差额目前缺乏确定依据，须结合履行地规则及协议效力判断。

2. **核实并追偿**：保存竞业协议、离职材料、约定收款账户流水及公司称已付款的聊天记录。书面要求公司提供付款日期、金额、收款账户和银行凭证，并核对款项性质；其他工资或报销款不能未经核对直接算作竞业补偿。按“2000元×到期未付月数”列出暂计欠款，扣除核实已付部分。

可发送：“本人未在约定账户收到×月至×月竞业补偿，暂计×元。请于收到本函后7日内提供可核验的支付凭证或支付欠款。本人保留追偿及依法请求解除竞业限制的权利。”

3. **是否停止履行**：因公司原因连续三个月未支付补偿，是请求解除竞业限制的重要依据；目前未提供欠付起止时间，且付款有争议，不能直接确认已满足条件。满足条件后可明确提出解除请求；公司不认可时，申请劳动仲裁，请求解除并支付欠款。自行设定的7日期限届满不等于自动解除，争议解决前宜避免直接入职竞争企业。

4. **30万元违约金**：数额约为月工资25倍，但不能仅据此认定无效。若发生索赔，可请求适当调减，并提交工资、履约情况及过错程度等材料，要求公司说明损失依据。同时核查你是否实际接触商业秘密、限制范围及期限是否合理；这些会影响义务及责任判断。
