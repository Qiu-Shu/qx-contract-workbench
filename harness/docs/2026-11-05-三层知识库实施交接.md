## 已接入的行为

入口为左侧“律所知识库 → 关系图与三层知识”。可切换图谱/列表，按项目和层级筛选，查看来源、修改确认、规则旧版本，按需读取历史原文。已有案件可沿用案件 ID；已有资料仅关联索引，原资料服务继续核验并分页读取。现有案件记忆与 Hindsight 集成保留，不增加第二套图数据库或 Jev 服务。

周整理默认周日 20:00（Asia/Shanghai），关闭期间下次启动补做。仅覆盖工作台会话；包含持久化旧会话和被正常上下文压缩保留的原始消息。不会将 compact-checkpoint 模型摘要当用户原话。首次分批处理，之后按提交成功的消息游标增量处理。默认周调用上限 100，可暂停、调整时间/限额、立即继续；错误和预算耗尽保留进度，不虚报成功。

规则确认默认仅当前项目，“确认并设为全局原则”才扩大到其他项目。经验摘要需律师去除身份信息后显式允许跨项目复用。未归属会话进入待归属，不自动混入任务上下文。原文更正、删除、移项会使旧派生条目退出召回；删除也清除派生正文和版本历史正文。

模型启动上下文是同步的当前项目索引和操作约束；knowledge_start 读取经校验的项目摘要及相关历史/原则，随后 knowledge_recall / knowledge_read 按需读取。单轮共享 20,000 字符上限，普通召回最多 8 条、每条 800 字符；历史原文要在界面授权，15 分钟内仅对相应条目有效。冲突比对由当前任务模型完成，提示中要求展示方案句、原则编号/版本与冲突理由；不是另一个独立法律裁判模型。

备份为分批 JSONL，恢复逐行提交，每份请求限制 2 MiB；包含派生条目、项目、绑定、来源删除记录、规则版本与资料索引。原始聊天、原件和 API 密钥不在该备份中。旧备份在新电脑恢复，无法得知备份之后的删除；恢复条目重新进入待确认。
