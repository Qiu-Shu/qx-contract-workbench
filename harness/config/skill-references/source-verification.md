# 法律依据与材料引用核验

本页供现有接待、合同审查、办案、模拟庭审及法律专项 Skill 按需共用。仅在回答依赖具体法律依据、材料事实或引文时执行相应部分；普通概念说明、语言整理和已核实材料的局部改写，不必重复整套检索。现有工具可用于查找和回读，检索命中、存档成功与法律判断成立是三回事。

## 先分清要证明什么

- 法律依据：需要说明哪一司法辖区、哪一时间点的规则。涉及历史行为时，同时关注行为发生时、争议发生时及当前规则，不能直接套用最新条文。
- 案件事实：区分当事人陈述、材料记载、已确认事实、推断和争议事项。某份材料存在，不等于其记载真实或证明目的成立。
- 律所知识：范本、经验和旧研究可帮助寻找问题及表达方式，不能自动证明现行法律或本案事实。
- 模型记忆和旧回答：只能作为检索线索，不能充当法源、逐字引文或事实证据。模拟庭审发言也不是证据。

## 需要具体法律依据时

使用现有 `legal_search` 查找，使用 `legal_search_read` 按工具返回的标识、分页或条文入口回读。只发送完成检索所需的抽象争点、法规名、条号和时间范围，避免夹带当事人身份信息或合同全文。工具当前不可用时说明未能完成哪一步，不编造搜索结果或已接通的数据库。

1. **确认范围。** 明确国家或地区、规则层级、事项和适用时间。全国性规定、地方规定、部门规章、司法解释、裁判案例、政策文件分别标识，不混作同一效力层级。
2. **回到原始发布来源。** 优先读取有权发布机关的正式文本及其数据库、公报。转载、商业检索结果和文章可提供线索；只有搜索摘要、跳转页或无法打开的链接时，不声称已核对原文。政府域名本身也不证明网页中的每个内容均为正式法律依据。
3. **核对版本。** 检查标题、发布机关、文号或可识别的版本、公布日期、生效日期以及修改、废止和过渡安排。区分现行有效、尚未生效、已废止与无法确认。正文与数据库状态不一致时继续找修订决定、废止公告或新版本，不凭较新的网页日期判断法律已更新。
4. **定位完整规则。** 读取所引条、款、项以及与结论有关的定义、前提、但书、例外、援引条款和附件。分段结果按返回的续读标识继续，读到足以支持本次结论即可，不强求全文入上下文。案例须区分裁判观点、案情和引用的规范，并说明对本案的适用差异。
5. **把引文和判断分开。** 逐字引用已读原文，随后说明适用理由和仍需确认的事实。不能把摘要改写后放进引号；未取得可靠来源时，不给确定条号、逐字法条或“现行有效”的确定结论。

正式意见中的关键依据应能回查：保留规范名称及版本、条款位置、来源链接、实际检索或抓取时间和相关原文。日期、发布机关或状态未查到就写未核实；工具未返回哈希、页码或位置时不自行编造。HTTP 成功、本机缓存存在和文件已下载都不能替代内容及现行性核验。

## 需要引用律所资料或案件材料时

- 律所资料使用 `mcp__qx_knowledge__search_knowledge`，不清楚可用资料时使用 `list_knowledge`。命中后将实际返回的引用编号传入 `read_knowledge_citation(reference=...)` 回读，必要时用 `read_knowledge` 按 `next_start` 续读。保留资料名、KB 编号、版本及返回的位置；短摘要不能冒充全文。
- 案件材料使用 `mcp__qx_legal__search_case_materials` 和 `read_case_material`，明确 `case_id`，查看命中 `kind`。笔记命中时，用 `read_case_note` 回读并追溯对应原始材料；旧笔记不自动升级为当前事实。文件已改变、缺失或只能读取历史解析快照时，如实说明版本限制。
- 保存已授权的办案或审查成果时，沿用 `record_case_note`。材料引文提交真实 `path` 和逐字 `quote`，仅在工具返回时附 `sha256`、`chunk`，不让模型计算字符偏移。网页来源链接和核验情况写入自然正文或 `source`，不要伪造为本地材料路径或 KB 编号。引用匹配失败时保留可用正文并标待核。
- 对 OCR 来源，影响结论的金额、比例、日期、期限、条号和否定词必须对照原始页图核实。页号和 OCR 文本块编号只是定位线索，不是准确率证明；无法查看原页时标明待核，不凭语义自动“纠正”后充作原文。

## 缺失、冲突和更正

缺少关键来源时，继续交付不依赖该来源的部分，指出具体待核点及其对结论的影响。可以给条件分析，但不要补造引用或将“未找到”写成“不存在”。

两个来源冲突时，并列指出冲突内容、版本、时间和来源性质；优先回查原发布机关的正式文本、修订或废止记录。仍无法排除冲突就保留不同可能及所需补证，不能只选对我方有利的结果。材料互相矛盾时，同样区分谁说了什么、何时形成、是否为原件及哪些内容尚无旁证。

后续取得新材料或新法源，只重核受影响结论并保留旧成果。已有明确案件时追加进展；只有用户明确更正旧记录才通过 `supersedes` 关联相应旧笔记，不覆盖原话。保存失败不能宣称已保存；核验未完成不能宣称已查证。
