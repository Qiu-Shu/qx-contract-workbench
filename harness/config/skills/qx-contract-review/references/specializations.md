# 合同专项按需选择

按协议实质和用户问题选择一个或少数几个工作流，不只凭文件名、单个关键词或甲乙方标签分类。同份协议多个方法按专业问题分工，避免同一风险换词重复展开。

| 场景 | 重点 | 可按需加载的完整 Skill |
|---|---|---|
| NDA、保密条款 | 先看是否混入排他、禁止招揽、竞业限制、知识产权转让/许可、优先购买、最惠待遇等隐藏义务；再查披露/接收方向、定义、用途、例外、强制披露、期限存续、返还销毁及备份。单方义务不当然违法。 | `legal-zh-commercial-nda-review` |
| 采购、供应、服务协议 | 按我方角色看范围、交付/验收条件、付款、续期解除、知识产权、保密、赔偿和附件。责任限制分清直接/间接损失、计算基数、限额和例外；分别给替换及备选。 | `legal-zh-commercial-vendor-agreement-review` |
| SaaS、订阅、云服务 | 在供应/服务基础上核对订阅范围、服务水平、自动续费、价格调整、停服、退出与数据迁移；不要把仅含“用于评估项目”的保密协议误作采购合同。 | `legal-zh-commercial-saas-msa-review` |
| DPA、数据处理附件 | 根据实际数据、处理目的、角色、子处理者、跨境、事件通知和返还删除安排，读取相关附件再分析。网页链接未读取就列为缺口。 | `legal-zh-privacy-dpa-review` |

用户仅问某一专项时直接处理该范围。原库的机构模板、审批流程、CLM/云文档连接器不代表本机已配置；缺少这些信息时先完成可完成的分析，只补问影响结论的事实。可编辑的候选条款和商业折中优先于形式上的完整表格。
