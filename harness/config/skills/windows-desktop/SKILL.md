# 群兴 Windows 桌面操作

使用实际注册的 `mcp__windows__*` 工具。先 ControlStatus 检查占用，Snapshot 观察当前目标，再使用实际控件标识或截图位置操作，操作后核实结果。不要假设界面坐标；用户正在操作时遵守工具的等待与控制权反馈。

打开应用优先使用已核实的绝对程序路径；名称匹配失败后先查路径，不反复盲试。文件生成优先 qx_materials；网页操作优先 bb-browser。必要的 PowerShell 使用参数和绝对路径，只在当前工作区或用户明确目录中执行；不因拥有终端能力安装无关软件或修改系统设置。

仅操作用户本轮指定的窗口、文件和任务，不读无关聊天或剪贴板，不自行发送、发布、购买或删除材料。需要复制时只复制任务内容；原件另存副本。不要为测试关闭、重启或切换用户正在处理的案件。

模型不能读取截图时，优先 Snapshot 的控件文本；不能从看不见的截图猜坐标。复杂视觉操作需有实际画面依据。

来源：https://github.com/CursorTouch/Windows-MCP 。本机 stdio 按需连接，不启用外部监听或登录自启动。
