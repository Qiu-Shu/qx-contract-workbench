# 内容稿与版式规范

## 一、版式参数（脚本已内置，此处供核对）

| 项目 | 取值 |
| --- | --- |
| 纸张 | A4，二十一厘米乘二十九点七厘米 |
| 页边距 | 上二点六、下二点四、左右各二点六厘米 |
| 版心宽度 | 十五点八厘米，表格列宽合计不得超过此值 |
| 正文 | 宋体小四（十二磅），一点五倍行距，首行缩进零点六厘米 |
| 一级标题 | 黑体十四点五磅加粗，段前十五磅、段后五磅，与下段同页 |
| 二级标题 | 宋体十二点五磅加粗，段前八磅、段后两磅，与下段同页 |
| 条目 | 左缩进一点五厘米、悬挂缩进一点五厘米，序号后接制表符 |
| 提示语 | 宋体十一磅，左右各缩进，用于表注与口径说明 |
| 表题 | 宋体十一磅加粗、灰色，与表格同页 |
| 表格 | 表线上框细线，表头浅灰底 F2F2F2 加粗，跨页重复表头 |
| 页脚 | 居中页码，宋体九磅灰色 |

两张附表各自加一个 pagebreak 区块，独占一页。正文末尾到附表之间必须断开，否则表格会被分页切断。

## 二、JSON 结构

顶层两个可选字段与一个必需数组：

```json
{
  "title": "某某法官背调与开庭提纲",
  "subtitle": "某某人民法院　某某条线　内部工作文件　二〇二六年十一月八日",
  "blocks": []
}
```

blocks 里每个对象带 type 字段，七种类型：

| type | 必需字段 | 说明 |
| --- | --- | --- |
| h1 | text | 一级标题，中文序号加顿号 |
| h2 | text | 二级标题，中文括号序号 |
| body | text | 正文段落，自动首行缩进 |
| item | num、head、text | 带序号的条目，head 加粗，text 接排 |
| tip | text | 提示语，用于表注、口径说明、待核实事项 |
| caption | text | 表题，自动与下张表同页 |
| table | headers、widths、rows | 表格，可选 font、center_cols、row_height |
| pagebreak | 无 | 强制分页 |

table 的 widths 为厘米数组，center_cols 为需要居中的列下标数组，默认首列居中。font 为表内字号，台账类小表用八点五，结论表用九点五。

## 三、最小可运行示例

```json
{
  "title": "示例提纲",
  "subtitle": "仅用于验证脚本",
  "blocks": [
    {"type": "h1", "text": "一、先看这一页"},
    {"type": "body", "text": "这一段用于验证正文缩进与行距。"},
    {"type": "item", "num": "1", "head": "身份。", "text": "这一条用于验证悬挂缩进。"},
    {"type": "pagebreak"},
    {"type": "caption", "text": "附表一　示例表"},
    {"type": "table",
      "headers": ["序号", "内容"],
      "widths": [2.0, 13.8],
      "rows": [["1", "示例行"]],
      "font": 9.5}
  ]
}
```

## 四、标点与数字

- 只用中文标点：顿号、逗号、句号、分号、冒号、括号、书名号、问号、叹号。
- 不出现半角括号、半角逗号、半角句点、斜杠、连字符、百分号、星号、箭头、勾选符号。
- 日期写全角中文：二〇二六年十一月八日，不写 2026-11-08。
- 比例写中文：百分之三十八点五，不写 38.5%。
- 案号写中文括号：（2026）鄂01民终15982号。
- 表格内的数字可用阿拉伯数字，因为数字不属于标点；但小数点的场合改用中文表述。

## 五、章节骨架

1. 一、先看这一页　三到五条结论，每条一句，读者只读这一页也能定方向
2. 二、已查实的事实　按阶段分，每条带时间、案号、合议庭、来源等级
3. 三、履历读法　条线判断、合议庭影响、晋升节奏、待核实
4. 四、数据缺口与替代口径　说清为什么查不到，再给三条替代路径与使用边界
5. 五、开庭提纲　调查五问、举证质证、辩论三层、最后陈述
6. 六、两条路线与本案取舍　主攻改判、主攻发回、不宜主攻
7. 七、庭前待办清单　按时间倒排，第一条永远是核实承办人
8. 附表一　首轮检索台账　渠道、检索式与结果、来源等级
9. 附表二　结论一页纸　十项，末两项是本案落点与主攻方向

条线不同时第五、六章要换问法。建设工程与房地产问结算依据、质保期、责任分配；劳动争议问工资构成、考勤加班、补偿基数、仲裁时效；合同类问解除时点、违约证据链、减损义务。不要拿通用五问糊过去。
