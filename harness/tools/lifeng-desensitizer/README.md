# 立丰脱敏

本地运行的文档脱敏工具，给刑事案件卷宗、合同这类材料做批量脱敏。

**所有处理都在本机完成，不联网、不上传。** 服务只监听 `127.0.0.1:8791`。

## 功能

- **规则脱敏**：身份证、手机号、银行卡、邮箱、车牌、地址、公司名、人名、金额、日期
- **扫描件 OCR**：调 macOS 自带的文字识别，本地跑，不联网
- **手动涂黑**：扫描件、照片专用，黑块可加备注
- **撤销**：手动涂黑和自动涂黑都能撤，按内容清理会一次清掉全文同类
- **预览确认**：结果先给你看，点了「导出」才进成品文件夹
- **去水印**：去掉 PDF 上后压的矢量文字水印（律师执业证号、律所名、「仅供××使用」这类）
- **一键还原**：Word 类文件可以拿映射表还原回真名
- **逆向还原**：把 AI 写的提纲/纪要里的占位符换回真名，支持多份映射表合并
- **转 Markdown**：给 AI 读的格式

## 运行

需要 macOS，Python 3.13。

```bash
pip install -r requirements.txt
python3 server.py
```

然后打开 <http://127.0.0.1:8791>。

首次运行会在 `~/Library/Application Support/立丰脱敏/` 下建工作目录（词表、映射表、预览任务、记忆库都在里面）。

## 目录

```
server.py          本地 HTTP 服务：脱敏/预览/导出/还原/去水印的接口与流程编排
web/               前端（原生 HTML + JS，无构建步骤）
engine/            脱敏引擎：分句、识别、占位符分配、docx/PDF 读写、去水印
app/App.swift      macOS 外壳（WKWebView 套本地服务）
```

引擎里几块核心：

| 文件 | 干什么 |
|---|---|
| `desensitize.py` | 主体：刑民分流、结构识别、占位符分配、docx 替换 |
| `chinese_names.py` | 中文姓名识别（姓氏表、名字用字表、角色词） |
| `watermark.py` | PDF 文字水印的识别与删除 |
| `mark_apply.py` | 把预览里手动标记的词落到导出文件上 |
| `preview_build.py` | 生成预览数据（脱敏后正文 + 替换点标记） |
| `terms_import.py` | 词条对照表导入（xlsx/csv/docx/txt） |

## 隐私

- 服务只回环监听，不接受外部连接
- 工作目录在 `~/Library/Application Support/立丰脱敏/`，不往别处写
- **映射表是还原钥匙**，存在 `工作区/对照表/`，别外发
- 代码里不含任何真实案件数据；示例与注释里的人名均为化名
