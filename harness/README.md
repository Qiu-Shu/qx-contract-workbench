## 开始使用

安装器适用于 Windows 10/11 x64，自带运行环境。首次启动填写自己的模型 API 配置；微信连接由本人扫码。用户资料默认保存在 `%APPDATA%/QunxingHarness`，也可使用已确认的数据目录。升级与卸载保留资料。

已有固定的 0.2.14、0.2.15、0.2.16 或已验收的 0.2.17 候选版，可沿原目录安装 0.2.18；更早版本按 0.2.6 → 0.2.7 → 0.2.9 → 0.2.10 → 0.2.14 → 0.2.18 顺序继续升级，0.2.5 及以前先手动安装 0.2.6。新用户选择空目录。被手工修改的程序会被严格基线检查拦住，详见[安装与更新](packaging/UPDATES.md)。

## 日常工作

| 能力 | 使用方式 |
| --- | --- |
| 客户接待 | 在会话中描述需求，分别生成可转发的律师回复与内部分析。 |
| 合同审查 | 添加附件后提出审查要求，默认另存批注版；明确要求时才修订正文，保留原件。可生成 HTML 与 Word 意见书。 |
| 材料整理 | 解析、检索、引用回看、文字对比；新材料首次解析自动登记，原件变化时须明确重新导入。 |
| 模拟法庭 | 五阶段、11 次发言逐条保存，支持回读、续接与复盘。 |
| 案件记忆 | 主动选入记录，按案隔离，保留来源，支持查看、更正、删除和增强检索。 |
| 法律资料检索 | 查询结果本机保存、分页回读；研究方法保留来源和待核验状态。 |
| 拓客内容 | 配置业务方向、目标客户、JustOneAPI 和模型服务；每 72 小时生成专用会话摘要，也可“立即整理”并打开会话。 |
| 备份与恢复 | 从桌面入口停止后台、创建加密备份；恢复到新目录，核对偏好和旧待办，再确认启用。需要时可撤回上一目录。 |

具体工具调用卡片显示中文名称，调用编号、参数与结果保留。模型和外部内容服务使用用户自己的配置，产生相应服务用量。

微信连续文字通常停发约 8 秒后处理，含附件约 12 秒；“还没发完”继续等待，“发完了”开始整理。关闭主窗口后后台可能继续运行；定时工作需要电脑开机、未休眠、后台运行且网络可用。

## 材料与隐私

上传前可选择标准或深度脱敏，逐份预览、编辑和确认后再加入附件。本机保留原件及映射，上传的是确认后的文字副本。自动识别可能遗漏，扫描与 OCR 也可能出现空格或识别误差，应检查姓名、机构等敏感内容；脱敏不等于法律或合规结论。

恢复备份不会自动连接账号或执行旧任务。先检查需要重连的项目及旧待办，再确认启用。原副本保留，可撤回上一目录。[备份恢复流程](docs/2026-11-13-restore-activation-delivery.md)
