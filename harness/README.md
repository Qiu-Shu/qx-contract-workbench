## 安装使用

下载 `Qunxing-Workbench-0.2.3-Setup.exe`，双击安装。无需另装 Node 或 Python。首次启动填写自己的 DeepSeek API Key；左下显示账户余额，微信入口由本人扫码连接。关闭窗口后后台继续处理微信，电脑需要保持开机、不休眠并联网；未设置开机自启。

用户资料和加密设置位于 `%APPDATA%/QunxingHarness`。升级保留已有资料、自定义规则和设置，卸载保留资料。安装包未签名，Windows 可能显示未知发布者；当前完成本机隔离安装、升级和卸载验证，尚未在另一台干净电脑验收。

## 已接入的工作

| 能力 | 当前行为 |
| --- | --- |
| 客户接待 | 可直接微信转发的律师回复与内部分析分别保存、分别导出。 |
| 合同审查 | 读取附件、保存审查意见、生成 Word；默认另存批注版并保留正文，明确要求时才修订正文。意见书同时生成 HTML 和 Word。 |
| 办案整理 | 持续整理时间线、证据缺口和待办；更正追加记录，保留原记录。 |
| 模拟法庭 | 五阶段、11 次发言逐条保存，支持回读、续接与复盘。 |

微信连续消息停发后合并处理：文字约 8 秒，含附件约 12 秒；说“还没发完”继续等待，说“发完了”立即统一处理。本机律所知识库只检索用户主动加入的资料。上传时可选择本机脱敏，原件和映射留在本机。

模型请求超时、断流或返回损坏参数时，沿用 Harness 官方机制恢复当前请求，保留已有内容、文件和成功工具结果；正常策略最多重试 5 次。用户停止可取消等待，认证和余额错误不盲重试。这是请求级恢复，不承诺任意外部工具或断电后的全局不重复执行。

## 材料与上下文

支持 TXT、Markdown、CSV、TSV、JSON、HTML、RTF、DOC/DOCX、PDF、XLS/XLSX、PPT/PPTX、ODT/ODS/ODP，以及 PNG、JPG/JPEG、WebP、GIF、BMP、TIF/TIFF。当前不含音视频转写。扫描件与图片在本机 OCR，识别内容需对照原件。

上传与微信材料分别保存在工作区 `inbox`、`wechat-inbox`，成果保存在 `drafts`；原件不覆盖。已去掉旧版 20 文件、100 MB 会话配额，大材料分段或分页读取。实际容量仍受硬盘、内存和上游 API 限制。上下文压缩保留工作摘要，原始会话和材料留在本机。

## 源码与开发

GitHub 中本目录位于 `harness/`；仓库根目录保留旧工作台及复用的 Python 文档解析器。现有开发机运行目录仍为 `D:/qx-harness-workbench-20261102`，依赖 `D:/qx-contract-workbench-20261102/.venv`、旧版 Electron 和本机工具路径。`启动群兴工作台.cmd` 是该开发环境入口，不能当作任意电脑解压即用的安装入口。

`package.json` 的 `0.1.0` 是内部集成包标识，安装产品版本由打包参数指定。依赖版本及中文界面补丁见 `pnpm-lock.yaml`、`pnpm-workspace.yaml`；构建说明见 [packaging/README.md](packaging/README.md)。移植开发环境时需调整启动脚本、`config/cordis.patch.yml` 和打包脚本内的本机路径，再安装对应依赖；此次同步未将它改造成通用跨平台构建工程。

法律库归档及许可证见 [sources/README.md](sources/README.md)。运行 `python scripts/prepare_legal_skills.py --workspace <工作区路径>` 可重建法律库；工作区、密钥、微信会话、脱敏映射、依赖缓存和安装包不进入 Git。文档工具见 [bridge/README.md](bridge/README.md)，微信来源见 [plugins/wechat/README.QX.md](plugins/wechat/README.QX.md)。
