# 更新机制（0.2.15）

发布仓库 `Qiu-Shu/qx-contract-workbench`。正式版本上传安装器、blockmap、原私钥签名的 latest.yml 及摘要清单；标签与构建源码一致。公钥未变，绝不跳过元数据或下载校验。

客户端启动后检查更新，也可从菜单检查。下载、取消与安装由用户操作；退出不自动安装，不限制旧版使用。下载差分失败不会自动改为整包下载，可从 GitHub 下载完整安装器。

首次安装选择空目录；增量安装接受官方0.2.14基线和同版安装恢复。旧版或被手工改动的程序会停止并保留文件；先升级官方0.2.14后再更新。资料、账号与加密设置不随卸载删除。安装中断通过原子替换和恢复记录处理，不以备份整个用户资料库实现。

构建与验证步骤见 [README](README.md)。历史记录在 `harness/docs`，不要把旧版基线和构建机器路径用于当前版本。
