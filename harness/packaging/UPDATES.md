# 更新机制（0.2.18）

0.2.18 已正式发布，GitHub Latest 指向本版。公开更新元数据、安装包完整下载及原签名核验通过；本机已完成升级并确认“检查更新”显示 0.2.18 为最新版。

发布仓库 `Qiu-Shu/qx-contract-workbench`。正式版本上传安装器、blockmap、原私钥签名的 latest.yml 及摘要清单；标签与构建源码一致。公钥未变，不跳过元数据或下载校验。更新签名不是 Windows Authenticode 发布者证书。

客户端启动后检查更新，也可从菜单检查。下载、取消与安装由用户操作；退出不自动安装，不限制旧版使用。优先下载变化部分，临时连接中断重试一次；增量无法完成时，转为带相同签名和 SHA-512 校验的完整包下载。取消、磁盘空间或权限错误直接停止。界面显示下载方式与对应大小。

首次安装选择空目录；增量安装接受固定的官方 0.2.14、0.2.15、0.2.16、已验收的 0.2.17 候选基线和同版安装恢复。更早或被手工改动的程序会停止并保留文件；更早版本按 0.2.6 → 0.2.7 → 0.2.9 → 0.2.10 → 0.2.14 → 0.2.18 顺序继续升级，0.2.5 及以前先手动安装 0.2.6。资料、账号与加密设置不随卸载删除。安装中断通过原子替换和恢复记录处理。

0.2.14/0.2.15 内的旧下载器没有完整包接续能力。下载反复失败时，从正式发布页手动下载新版，关闭工作台后沿原目录安装一次，无需卸载或清除资料。网络无法连接发布服务时仍需恢复连接。

构建固定依赖 0.2.14–0.2.16 官方安装包及 0.2.17 基线归档，保留这些附件。0.2.17 归档随 0.2.18 发布，仅用于可复现构建和升级基线核对，普通用户应下载 0.2.18 的 Setup.exe。0.2.6、0.2.7、0.2.9、0.2.10 过渡包继续保留。新版公开核验后，已清理 0.2.1–0.2.5 共 16 个安装器及配套更新附件，保留历史代码标签与发行说明，并补充升级指引。

构建与验证步骤见 [README](README.md)，实际发行证据见 [0.2.18 发布记录](../docs/2026-11-13-0.2.18发布.md)。
