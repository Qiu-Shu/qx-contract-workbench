# 更新机制（0.2.17 候选，沿用 0.2.16 下载恢复）

本分支为本地候选，尚未发布；本轮仅生成未签名元数据，正式更新校验仍会拒绝它。

发布仓库 `Qiu-Shu/qx-contract-workbench`。正式版本上传安装器、blockmap、原私钥签名的 latest.yml 及摘要清单；标签与构建源码一致。公钥未变，绝不跳过元数据或下载校验。

客户端启动后检查更新，也可从菜单检查。下载、取消与安装由用户操作；退出不自动安装，不限制旧版使用。优先下载变化部分，临时连接中断重试一次；增量无法完成时，转为带相同签名和SHA-512校验的完整包下载。取消、磁盘空间或权限错误直接停止，不继续切换下载。界面显示当前下载方式与对应大小。

首次安装选择空目录；候选构建的增量安装接受官方0.2.14、0.2.15、0.2.16基线和同版安装恢复。更早或被手工改动的程序会停止并保留文件；先升级官方0.2.14后再更新。资料、账号与加密设置不随卸载删除。安装中断通过原子替换和恢复记录处理，不以备份整个用户资料库实现。

0.2.14/0.2.15内的旧下载器没有上述恢复能力。如重复提示“未改为下载整包”，从正式发布页手动下载0.2.16，关闭工作台后沿原目录安装一次；无需卸载或清除资料。网络本身无法连接发布服务时仍需恢复连接。

构建与验证步骤见 [README](README.md)。历史记录在 `harness/docs`，不要把旧版基线和构建机器路径用于当前版本。
