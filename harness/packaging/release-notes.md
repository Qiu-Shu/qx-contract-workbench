# AI师兄法律助手平台 0.2.18

本版汇总 0.2.16 审核整改，并纳入律师拓客、桌面备份恢复和材料解析改进。

## 更新内容

- “拓客内容”按业务方向、目标客户整理小红书内容，每 72 小时生成专用会话摘要，支持立即整理和打开会话。使用用户自己的 JustOneAPI 与模型配置。
- 桌面“备份与恢复”支持本地加密备份、隔离恢复、配置检查、旧待办处置、确认启用及撤回；保留原副本，不自动连接账号或执行旧任务。
- 新材料首次解析自动登记，已登记原件变化仍须显式重新导入；修复长 Windows 路径、扫描续表、混合 PDF 和中文姓名脱敏问题。
- 具体工具名称显示中文，保留工具编号、参数和结果；保留知识正文和来源状态，修复项目归属并保护微信本地凭据。
- 增加合同文字对比、原件版本核验后的引用回看，以及法源核验、类案比较、争点备忘录、讲座来源包四项研究方法。

## 下载与升级

普通用户下载 **Qunxing-Workbench-0.2.18-Setup.exe**。新用户选择空目录；匹配的官方 0.2.14、0.2.15、0.2.16 和已验收的 0.2.17 候选版沿原目录升级，无需先卸载。更早版本先通过官方 0.2.14 过渡；手工修改过的程序文件仍须通过基线核验。

更新沿用原 Ed25519 签名及下载摘要校验。旧版下载反复失败时，可手动下载安装器升级。用户资料和加密配置保留；安装包不包含真实案件、密钥或微信登录态。

**Qunxing-Workbench-0.2.17-baseline-archive.exe 仅为源码重建所需的旧候选基线归档，普通用户无需下载或安装。**
