Windows x64 安装包与对应应用源码同步更新到 **0.2.15**。

### 安装

- 新用户下载 `Qunxing-Workbench-0.2.15-Setup.exe`，选择一个空文件夹安装，无需另装 Node 或 Python。
- 已安装官方0.2.14的用户关闭工作台后，沿用原目录升级。账号和资料保留。
- 0.2.13及更早版本请先安装[0.2.14](https://github.com/Qiu-Shu/qx-contract-workbench/releases/tag/v0.2.14)。手工修改过程序文件的安装可能被基线校验拒绝，不能用本包强制覆盖。

### 本版变化

- 修复技能目录和工具目录不一致，保留旧用户自定义配置。
- 改善启动等待与自动重连，保留未发送输入，不自动重发中断任务。
- 加入律师个人账号运营入口和律师工作助手简介。
- 合并知识库与案件记忆入口，自动整理当前工作的来源摘录和附件索引；保持三层按需读取及每轮共享16 KiB预算。
- 修复切换案件、纠正来源、重复分页、旧快照及并发保存问题。
- 补齐此前安装版缺失的应用源码、默认资源和依赖修补；打包不再依赖开发者机器目录。
