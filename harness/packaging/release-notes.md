# 0.2.17 审核整改候选

当前仅为本地验收候选，尚未正式发布或安装到用户工作台。自动更新元数据未签名，不提供正式发布链接。

## 本版变化

- 迁移后原件暂不可读时保留知识正文、引用和历史；合并旧备份遵从当前项目归属，冲突有记录。
- 微信账号和上下文凭据使用当前 Windows 用户的 DPAPI 保护；媒体来源配置纳入可追溯源码。
- 新增法源核验、类案比较、争点研究备忘录和法律讲座来源包四项研究方法；来源、时间、地域、版本与未核验状态可保存回读。
- 合同两版只读文字对比，核验原件摘要后回看对应文件、段落和 PDF 页面；可沿原输入框准备草稿，保留原件。
- 24 个合成工作流形成开发侧基线。评测依赖、备份实验、Presidio 和 Docling 不进入安装包。
- 增量安装基线增加官方 0.2.16，继续保留 0.2.14 与 0.2.15。

## 安装与验证边界

正式发行后的安装流程沿用原有空目录首次安装及原目录升级；手工改动的程序文件仍须通过基线核验。开发候选不能代替正式发布或跨机器验收。

当前本机验收使用独立目录和虚构材料，不读取用户账号/案件，不调用真实模型或真实微信。法律质量、另一台实体电脑及正式更新签名仍需后续验收。DPAPI 凭据绑定当前 Windows 用户，复制文件不等于可跨机登录。合同差异只比较已提取文字，不代表完整版式或法律影响判断。

实际安装包、升级回放及首次启动结果见 [候选交付记录](../docs/2026-11-12-candidate-package-acceptance.md)；先前源码验证见 [审核后续记录](../docs/2026-11-12-audit-followups-delivery.md)。
