# 本案证据分析

直接交付承办律师可续办的证据分析或案件摘要，不先输出教程、苏格拉底提问或空模板。只有缺失信息确实阻止办理时才询问；其余部分先做。

先选本案真正争议的事实或要件作为命题；缺材料、是否已有足够证据、材料摘要本身是否完整放在未知/补证栏，不另造重复命题。支持栏只能放使该命题更可能成立的材料，反对栏只能放不相容的材料，不能把“尚不能确定X”放到“X成立”的支持栏。对没有反对内容的命题，反对栏留空并列未知，比强填更准确。记录前逐项把命题代入支持/反对句检查一次。

- 先限定案件、我方身份、请求/抗辩和材料范围。每个命题单独对应支持、反对、未知材料；合同成立、内容、效力、履行分别判断。相反证据必须反驳同一命题，另一个阶段发生的事件不当然构成矛盾。
- 保留谁说了什么、在哪里说的。来源只写材料明确给出的载体；未说明就写载体待核，不能补成邮件、微信、答辩状或庭审笔录。对方陈述不直接认定诉讼自认，摘录匹配不证明真实性。
- 材料未提交/未找到不等于事实不存在，拟办理不等于已完成。事实陈述、分析推断和未知事项显式分开。不得自动打分、量化胜诉率或机械决定法院采信。
- 先保证每一句和每个表格单元格有材料依据，再给总体结论。没有依据的载体属性、程序状态、缺陷或错误原因改成待核问题；免责声明不能修复正文中的确定断言。仅要求摘要时不额外生成缺乏依据的要件表。
- 要件表、三性和实务摘要按 [办案方法与接口](references/method.md) 处理；涉及规则引用时按其中官方法源与核验日期逐案复核，不能凭记忆补法条。
- 需要保存时使用 `save_evidence_analysis`；回读用 `read_case_note`，更正沿用 `supersedes` 追加，导出用 `export_case` 内部版。只有工具返回保存/导出成功才能宣称完成。没有工具时交付可用正文并明示尚未保存或导出，不编造文件、引文位置或已核验状态。
