# 发明披露初步评估

## 任务

整理技术与权属线索，为专利检索及专业评估准备材料。

## 输入证据

技术问题、解决手段和效果、区别特征、贡献者、工作及合作背景、披露事件和日期、已有检索与商业目标。

## 关键判断

1. 贡献及事件表逐项记录原话、提出者、日期类型和证据。“提交”不替代公开或申请；合同栏只能写已提供文件、明确不存在的陈述或未提供，不能把后一项缩写成无合同。
2. 技术效果按“提出的效果主张/测试材料/验证充分性/补充测试”四栏处理。无对照材料的结论是效果未验证，实际效果是否成立仍待证。
3. 按区别技术特征、新颖性线索、创造性问题、主题、可检测性与商业目标提出具体调查。未经检索不能作可专利性定论。
4. 存在公开线索时保留事件、方式和范围；例外、期限与起算须从拟申请法域规则核验后判断。贡献与权属独立分析，职业或合作身份不自动确定权利。
5. 交付补证、检索和专业评审建议，保持公开日、申请日、完成日各自状态。

## 输出

技术效果四栏表；贡献/文件提供状态；事件表；筛查问题；公开规则待核与下一步。

## 证据与执行

先用本次材料完成可做部分。每项事实保留来源、陈述者和状态；“拟议”“未明确”“未提供”“未查询”分别记录，不能改写成已约定、不存在或查询无结果。业务负责人不自动成为审批人，机构名称不自动成为委托客户。

真实法律判断先取得适用法域、时点、官方原文和具体定位，再判断主体、触发条件与例外。无法核验的那一问题列待核，不用记忆、原库模板或具体条号当占位。仅有假设规则时按其明示要求逐项分析，其他问题列独立待核或建议，不把额外义务归入给定规则。

仅读取当前明确授权材料；实际文件可用材料解析工具，规则检索用真实可用的官方来源工具。无工具仍交付草稿及证据需求，列明未执行项目。仅在用户要求保存时写入已核实的当前事项位置并回读；报告完成状态以工具返回为准。对外发送、提交、审批或系统变更须有对应明确授权，不因调用本技能自动执行。
