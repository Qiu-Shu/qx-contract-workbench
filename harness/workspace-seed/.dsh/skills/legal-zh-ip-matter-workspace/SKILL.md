# 知识产权事项管理

## 任务与路由

REQUIRED SUB-SKILL: 使用 qx-case-work 的当前事项、材料导入、追加记录与成果保存流程。本入口只增加 ip 专业字段；不另建文件型案件系统，不读写旧 Claude 全局配置。

## 输入证据与专业字段

只用当前事项的已知标识、用户目标与授权材料。专业字段：资产及权利类型、权属主张和证据、合同与登记标识、披露及期限线索、许可及争议。机构、委托客户、相对方、监管机关与依据文件分别记载；未确认的委托关系、保密等级、公开状态和关联事项填“待确认/未核验”，不能默认为标准、未公开或无关联。

## 关键判断与落地

1. 已有明确 case_id 时核对后续接；同名或简称不能当作实际 case_id。新建授权交由 qx-case-work 执行，不重复询问用户已经明确要求的独立事项。
2. 切换只选择真实标识对应的当前事项，不修改全局活跃指针，不读取其他事项正文。原库 new/list/switch/close 词仅为意图；只执行真实工具支持且已授权的动作。
3. 用户只要方案、禁止写入或工具不可用时，交付事项卡和操作方案并标“未创建”；不得伪造ID、保存位置或成功结果。用户明确要求文件布局时，可提供该指定位置的候选结构，但不把它说成工作台内置存储机制。
4. 把补证和业务建议与已执行动作分列；归档等状态变更必须核实目标和实际工具结果，不能自造迁移目录或默认删除。

## 输出

事项标识及来源；专业字段表（已知/待核/来源）；当前授权范围；拟议或真实执行动作及结果。共享流程不可用时保留可审阅事项卡并说明未保存。
