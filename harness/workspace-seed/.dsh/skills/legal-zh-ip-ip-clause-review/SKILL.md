# 知识产权条款审查

## 任务

根据协议原文、适用法域与交易目标提出逐条修订候选。

## 输入证据

合同及附件、交易角色、背景知识产权、拟生成成果与改进、权属链、许可目标、法域及谈判立场。

## 关键判断

1. 确定实际协议覆盖范围。没有原文就给谈判议题，有摘录就只对摘录作发现；背景、新成果、改进及第三方权利分别整理。
2. 权属链记录贡献者、主张者、文件及尚未确认部分；没有提供文件不证明权利或书面约定不存在。
3. 开源/第三方条目只填“清单标签/实际许可文本来源/真实使用/已验证义务”。没有实际许可文本时最后一栏固定为待核；不因常见标签生成署名、源码或其他义务，可转 legal-zh-ip-oss-review 补查。
4. 归属、许可、保证赔偿、终止和责任限额逐条给原文、问题及条件性候选稿。跨法域转让和人身权安排分别核可行性，不作统一强制方案。
5. 核查条款一致性并列未决选择，结论为审查建议而非签署批准。

## 输出

材料范围；权属链；原文/问题/候选条款/适用条件；第三方许可四栏记录；待决项。

## 证据与执行

先用本次材料完成可做部分。每项事实保留来源、陈述者和状态；“拟议”“未明确”“未提供”“未查询”分别记录，不能改写成已约定、不存在或查询无结果。业务负责人不自动成为审批人，机构名称不自动成为委托客户。

真实法律判断先取得适用法域、时点、官方原文和具体定位，再判断主体、触发条件与例外。无法核验的那一问题列待核，不用记忆、原库模板或具体条号当占位。仅有假设规则时按其明示要求逐项分析，其他问题列独立待核或建议，不把额外义务归入给定规则。

仅读取当前明确授权材料；实际文件可用材料解析工具，规则检索用真实可用的官方来源工具。无工具仍交付草稿及证据需求，列明未执行项目。仅在用户要求保存时写入已核实的当前事项位置并回读；报告完成状态以工具返回为准。对外发送、提交、审批或系统变更须有对应明确授权，不因调用本技能自动执行。
