# AI师兄法律助手平台

面向律师的 Windows 桌面工作台：在一个输入框里处理接待、合同审查、材料整理和模拟法庭，也可按业务方向持续整理拓客内容。

**0.2.18 正在进行发布验收；当前公开版为 0.2.16。** [公开下载](https://github.com/Qiu-Shu/qx-contract-workbench/releases/latest) · [0.2.18 验证记录](harness/docs/2026-11-13-0.2.18发布.md) · [使用说明](harness/README.md) · [源码构建](harness/packaging/README.md)

## 0.2.18 的更新

- **律师拓客**：在“拓客内容”设置业务方向与目标客户，每 72 小时整理小红书内容到专用会话，也可立即整理。需配置自己的 JustOneAPI 和模型服务，相关用量由用户承担。
- **备份与恢复**：从桌面入口停止后台后创建本地加密备份，恢复到新目录，核对配置和旧待办，再确认启用；支持撤回到上一目录。
- **材料处理**：新材料首次解析自动登记；已登记原件发生变化仍需明确重新导入。改善长 Windows 路径、扫描续表、混合 PDF 文字和中文姓名脱敏。
- **工具与知识**：具体工具名称显示中文；保留迁移后的知识正文与来源状态，修复备份项目归属，保护微信本地凭据；新增合同文字对比、引用回看及四项中国法研究方法。

## 安装与升级

Windows 10/11 x64，安装器自带 Node、Python 和文档工具。首次启动填写自己的模型配置；微信由本人扫码连接。

新用户下载正式发布页中版本最高的 `Qunxing-Workbench-…-Setup.exe`，选择空目录安装。已有匹配的官方 **0.2.14、0.2.15、0.2.16** 或已验收的 **0.2.17 候选版**，可用 0.2.18 沿原目录升级，无需先卸载。更早版本先通过 [0.2.14](https://github.com/Qiu-Shu/qx-contract-workbench/releases/tag/v0.2.14) 过渡。手工改动过的程序文件可能被严格核验拦住，安装器不会强行覆盖。

软件内可检查更新，支持取消、稍后安装、增量下载失败后转完整包。旧版下载器反复失败时，从正式发布页手动下载并沿原目录安装。更新沿用原 Ed25519 签名与下载摘要校验；这不是 Windows 发布者证书，Windows 仍可能显示未知发布者。

用户资料默认位于 `%APPDATA%/QunxingHarness`，也可使用已确认的数据目录；升级和卸载保留资料及加密配置。发布包不含密钥、微信登录态、真实案件或脱敏映射。

## 开发与历史

当前产品源码在 [`harness/`](harness/)。构建从固定摘要的已发布二进制复用第三方运行环境，再叠加本仓库源码；并非从源码重编全部第三方组件。0.2.14–0.2.16 安装包及 0.2.17 基线归档是可复现构建所需附件，不应清理。普通用户应选择新版 `Setup.exe`，无需下载 `baseline-archive.exe`。

根目录 Python 工程是保留的历史版本及文档解析来源，[旧版说明](README.legacy.md)中的 0.6.x 与 Harness 版本不属同一条版本线。[历史交付记录](harness/docs/) · [更新机制](harness/packaging/UPDATES.md)
