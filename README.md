新版源码位于 `harness/`。根目录的 Python 工程和旧版桌面保留历史，并提供新版复用的文档解析/OCR；[旧版 README](README.legacy.md) 中的 0.6.x 是另一条版本线，不能与 Harness 版按数字比较。远端已有合同拒收回退修复保留。

安装包自带运行环境，首次启动输入自己的 DeepSeek API Key，微信由本人扫码。用户资料保存在 `%APPDATA%/QunxingHarness`，升级和卸载保留资料。安装包未签名，尚未在另一台干净电脑验收。

源码开发仍依赖已记录的本机工具路径，迁移前先阅读 [开发与构建说明](harness/packaging/README.md)。工作区、密钥、微信登录态、客户原件和脱敏映射不进入 Git；安装程序作为 Release 附件分发。
