# AI师兄法律助手平台

0.2.9 汇总三层知识库与关系图、High思考自动整理、本人微信桌面文件回传、三个限定来源方法，以及新会话和脱敏复核修复。共190个入口、154个可自动调用，36项旧方法及五项完整候选继续停用。正式增量安装基线为0.2.7；复杂法律输出仍须承办律师复核。

0.2.6 合入案件记忆、法律资料检索和逐份脱敏预览。真实 DeepSeek 调用已验证记忆提取、按案召回、来源、更正及删除，模型能实际调用记忆工具作答；保留已有启动恢复、文档预览和中文 Skill 名称。0.2.3 用户可通过律所知识库上方黄色升级按钮增量更新；0.2.2 及更早版本需手动安装一次新版。旧版继续可用。[更新与发布说明](harness/packaging/UPDATES.md)。

新版源码位于 `harness/`。根目录的 Python 工程和旧版桌面保留历史，并提供新版复用的文档解析/OCR；[旧版 README](README.legacy.md) 中的 0.6.x 是另一条版本线，不能与 Harness 版按数字比较。远端已有合同拒收回退修复保留。

案件记忆仅处理主动选入的记录；首次增强检索需在侧栏一键准备本机组件，分析使用已保存的 DeepSeek 密钥并产生模型用量。脱敏材料可逐份对照、调整后加入附件。

安装包自带运行环境，首次启动输入自己的 DeepSeek API Key，微信由本人扫码。用户资料保存在 `%APPDATA%/QunxingHarness`，升级和卸载保留资料。安装包未签名，尚未在另一台干净电脑验收。

源码开发仍依赖已记录的本机工具路径，迁移前先阅读 [开发与构建说明](harness/packaging/README.md)。工作区、密钥、微信登录态、客户原件和脱敏映射不进入 Git；安装程序作为 Release 附件分发。
