# AI师兄法律助手平台

面向律师的 Windows 桌面工作台：在一个输入框里处理接待、合同审查、材料整理和模拟法庭，也可按业务方向持续整理拓客内容。

**当前版本：0.2.19。** [下载 Windows 安装包](https://github.com/Qiu-Shu/qx-contract-workbench/releases/download/v0.2.19/Qunxing-Workbench-0.2.19-Setup.exe) · [发布说明](https://github.com/Qiu-Shu/qx-contract-workbench/releases/tag/v0.2.19) · [验证记录](harness/docs/2026-11-15-0.2.19发布.md) · [使用说明](harness/README.md) · [源码构建](harness/packaging/README.md)

## 0.2.19 的更新

- **原对话内并排对比**：从文件预览带入原稿，选好修改稿立即比较；保留完整上下文，标出新增、删除和具体修改。
- **少点击、少填写**：自动复用当前文件、对话和已有立场，支持同步滚动、变化定位与返回对话，保留对比结果。
- **文字差异与法律分析分开**：文字比较在本机完成；只有点击“分析修改影响”才通过原对话提交 AI 请求。金额、日期和违约责任标签只表示文字变化。
- **飞书共用对话**：本人飞书机器人可收发消息和合同，直接使用程序里的已有对话；粘贴飞书 docx、旧 doc 或知识库链接，可按应用权限读取正文。首次配置与配对后日常无需重复输入。
- **保护已有工作**：草稿或附件未发送时不会覆盖输入；切换对话、案件或文件版本后拒绝过期请求。

## 安装与升级

Windows 10/11 x64，安装器自带 Node、Python 和文档工具。首次启动填写自己的模型配置；微信由本人扫码连接；飞书在“飞书连接”中填写应用配置，并以一次配对消息绑定本人。详见[飞书接入说明](harness/plugins/feishu/README.md)。

新用户下载正式发布页中版本最高的 `Qunxing-Workbench-…-Setup.exe`，选择空目录安装。已有匹配的官方 **0.2.14、0.2.15、0.2.16** 、已验收的 **0.2.17 候选版** 或官方 **0.2.18**，可用 0.2.19 沿原目录升级，无需先卸载。更早版本按 **0.2.6 → 0.2.7 → 0.2.9 → 0.2.10 → 0.2.14 → 0.2.19** 顺序，在自己版本之后继续安装；0.2.5 及以前先手动安装 0.2.6。各过渡包在 [历史发布页](https://github.com/Qiu-Shu/qx-contract-workbench/releases) 保留。手工改动过的程序文件可能被严格核验拦住，安装器不会强行覆盖。

软件内可检查更新，支持取消、稍后安装、增量下载失败后转完整包。旧版下载器反复失败时，从正式发布页手动下载并沿原目录安装。更新沿用原 Ed25519 签名与下载摘要校验；这不是 Windows 发布者证书，Windows 仍可能显示未知发布者。

用户资料默认位于 `%APPDATA%/QunxingHarness`，也可使用已确认的数据目录；升级和卸载保留资料及加密配置。发布包不含密钥、微信登录态、真实案件或脱敏映射。
