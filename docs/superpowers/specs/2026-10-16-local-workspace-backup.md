# 本机工作区完整备份与独立恢复

依据用户已批准的本机原件、备份恢复、Windows 成品及无人值守要求。基线 42ffddc；已有全量法律资料库备份独立保留，不将 48 GB 法库重复装入案件备份。现有 synthetic-only 备份协议和门禁不变。

本批交付：本机原生入口暂停本应用后台服务后，使用 worker.lock 防止其他实例运行，SQLite backup 截取数据库，核对工作区标记、精确结构、身份、完整性和外键。收集 protected 下全部普通文件，逐一保留相对路径、长度和 SHA256，核对数据库中的原件及导出引用。包含全部本机账户、案件、接待版本、原件、来源证据、历史导出及审计。排除浏览器缓存、日志、运行锁、外部法库和旧升级快照；这些不属于当前案件截面。

归档使用独立 12–128 字符口令、scrypt 固定参数和 AES-256-GCM 认证加密。口令只通过本机进程管道传递，不进入参数、日志、设置或归档。新归档先临时写入并解密复核后发布；不覆盖已有文件。首版上限 2 GiB、20,000 个文件、单文件 512 MiB，超出明确失败；流式复制加密，不将整个归档放内存。归档自带时间和摘要是完整性证据，不证明资料真实性、最新性或法律效力。

恢复验证必须在新目录完成，严格检查路径、重复/大小写冲突、链接、文件数与大小、哈希、数据库结构/身份及引用。先核对原截面，再撤销历史会话、阻断未完成任务、保留当前批准隔离，复用现有文件位置映射以读取旧绝对路径导出。原件和历史 payload 不改。只读恢复副本用于核对，不能自动恢复签发、对外调用或业务写入；原工作区原样保留。桌面可打开恢复副本并回到原工作区，旧账户重新登录。只读模式必须服务端执行，并有明确提示及历史文件读取入口。

Windows 原生设置页面提供备份与恢复口令，文件/目录由主进程选择，业务网页不得调用这些维护权限。关闭/失败时原资料仍可打开，残留未完成目录不能当成功备份。操作失败显示可理解的固定错误，不显示口令或材料正文。

验收仅使用独立合成材料，包括不在虚构注册白名单中的本机 DOCX；实机走通备份、错误密码、恢复、重新登录、原件及历史 Word 核对、接待历史、恢复只读、返回原工作区。保留原 synthetic 备份测试，并核验安装包。该批不宣称生产密钥托管、联网账户/SMS、跨设备角色实时撤销、法律有效性核验或自动可写灾备切换已完成。
