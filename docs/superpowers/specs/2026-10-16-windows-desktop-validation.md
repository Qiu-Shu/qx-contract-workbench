# WIN02 Windows 桌面验证版

依据：用户已确认《2026-10-14-windows-unification》方向并授权无人值守继续；现有库已于 10 月 15 日完成全量检索和恢复验收。本次复用合同工作台，不重新建设业务引擎。

## 范围与验收

Electron 承载既有 FastAPI/Jinja 页面，Windows 安装包携带 Python 运行环境。首次启动在本机设置账户；后续沿原有登录和授权进入工作台。使用独立虚构工作区贯通 DOCX 导入、原文核对、Word 导出；现有法律资料库按本地路径接入，不打进安装包。

软件资源只读，用户数据放 Windows 用户应用数据目录。初始化不能覆盖已有目录。后端仅监听系统分配的回环端口；桌面只管理自己启动的进程，关闭或父进程异常退出应终止该进程并保留数据。并发启动不得创建重复 worker。页面不能获得 Node 或任意文件/进程访问权限。

保留原有密码、角色、CSRF、同源、案件权限、来源登记、版本与审核规则。账户设置通过窄 IPC 传入独占子进程的标准输入，不写命令行、日志或明文配置。未知错误只显示固定提示。

安装验证：中文且含空格的安装和资料路径、首次设置、二次登录、窗口缩小、100/125/150% 渲染比例、重启、后端异常、导出、退出无残留进程。记录产物大小、启动时间、内存、实际测试数量和限制；不将模拟缩放等同于更换 Windows 用户或干净第二台电脑验收。

## 本轮边界

仅本机验证；使用合成材料，现有真实案件工作目录不动。仅选择和读取已授权的资料库。不启用真实模型、QCC、收费服务、云部署、外发或自动更新。安装包未签名；完整统一界面、手机号/邀请/设备管理、签名更新、干净机器验收另有任务，不能称本轮生产完成。
