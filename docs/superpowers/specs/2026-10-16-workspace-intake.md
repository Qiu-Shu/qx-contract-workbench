# 统一工作区与获案接待首版

依据：用户已批准的统一 Windows 执行口径及无人值守指令；基线 a2a89ac。沿现有分支增量实现，不另建应用。此前全量法库、WIN02 安装实测已完成，不重复导入。

## 本批交付

- 新工作区首页 `/workspace`：接待跟进、待补材料、当前有权访问的合同案件、运行任务入口。既有 `/` 合同入口继续兼容，登录后进入新工作区。
- 接待登记、咨询原话、追问清单、材料清单及收到/核对状态、下次跟进时间和说明。支持全部咨询主题的文字登记；本批转案仅对接已有四类合同引擎，明确类型，不把家事或庭审引擎伪装完成。
- 客户回复与律师内部意见用独立字段保存，分开显示、复制、导出 Word。客户稿仅包含回复、编号、版本及草稿标记；不得带出咨询原话、联系方式、追问、材料或内部意见。导出绑定当前版本，客户稿需明确核对该版本文字；不发送给任何人。
- 每次保存追加不可改的快照，旧版本可读。更新使用预期版本，冲突返回 409。创建重试、转案重试不重复产生案件；转案原子保存关联，不把接待文字当成已核事实或已导入原件。已转案接待只读，附件继续在既有合同入口逐份确认导入。
- 接待默认仅本人可读写，现有登录、CSRF、同源与律师角色校验继续生效，非负责人不能通过猜测 ID 读取、修改、导出、转案或历史；转案后还需保有合同案件权限。
- 导航呈现六类业务的真实状态；未接入模块明确标注待接入。法律资料库保留独立检索、来源和待核状态。切换接待使用完整页面导航，当前记录 ID 固定在页面，不复用上一接待的表单/异步请求；案件仍沿现有独立 URL。

## 兼容和界面

既有数据库结构摘要不可绕过。首次升级前验证现有身份/结构及完整性、保存独立 SQLite 快照；仅添加固定的接待表/索引/触发器。数据库升级事务与标记更新间断电必须可恢复；只允许精确匹配的本次扩展，未知改动拒绝。旧数据库和原件不被重置。备份只在本机用户资料目录，不上传；验收仅独立合成工作区。

界面继承现有浅色、克制蓝色强调、系统中文字体，Impeccable Operate。用户已明确布局和无人值守，不重复设计访谈或概念选择。大屏导航/操作/接待原话，小窗口自然叠放；正文可调字号，键盘焦点、保存中、失败、空列表和版本冲突必须可见。保留旧入口和全部权限，不引入前端框架或外部资产。

## 验收与边界

API：不同账户/角色、撤权、CSRF、伪造字段、旧版本、重放/并发转案、客户稿排除内部内容、原子回滚、历史不可改。迁移：旧资料保留、备份匹配、结构篡改拒绝、事务中断/标记写入失败恢复。实机：新装/旧版合成数据升级、登记到导出和转案、重启、两接待切换、宽窄窗口。

本批不是全部统一平台完成：本机真实材料全量备份/恢复、跨三个引擎的附件交接、内容创作、个人记忆、家事和持衡接入、邀请/SMS/设备、签名升级及阿里云仍属后续。不得用本批接口测试替代法律效果或全功能验收。
