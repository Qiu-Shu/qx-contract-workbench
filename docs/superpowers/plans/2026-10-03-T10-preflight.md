## HTTP事务、job生命周期及恢复

当前get_db以yield把database.session保持到响应处理结束；authenticate/authorize读也触发T02 engine BEGIN IMMEDIATE。FastAPI同请求Depends缓存Session不会自动让T08 factory无锁。必须区分：短CRUD只加入caller事务；工厂/long job/stream不用带着get_db的Actor依赖进入下一数据库/网络事务。

1. 短事务A：authenticate cookie、verify_csrf（所有写）、对象归属、当前roles/member/action、输入/版本、幂等。start_job同时写JobInput.parameters_sha256对应的受保护完整参数、matter关系、当前expected hash和queued事件，成功commit后才返回202/job_id。客户端不能提交自己的JobStatus/state/result_ref/approved标记。
2. 单worker短事务B：条件queued→running领取，写claim token/currentversion及事件并commit；Session不跨线程/async-task复用。worker持有显式Database，不持请求Session/Request或只有cookie字符串。实际执行前再次核验actor会话/角色/成员和当前业务版本；失效则blocked，0外部发送。
3. 无HTTP事务执行：本地parse/review或T08网关，由各已完成阶段的真实合同保证短持久边界。T06当前mock加入caller事务不涉及付费网络，未来real provider仍先治理；不能把目前run_review服务直接当耐久任务系统。解析原件服务当前也做DB读取，若事务范围覆盖全部CPU解析，先测响应锁占用，必要窄分成授权/不可变bytes复制→无Session pure parse→重授权/保存，而不是改全局BEGINIMMEDIATE。
4. 短事务C：再次核验expected document/fact/rule/policy/position/hash和实际session，原子保存业务result和job终态/事件；状态变化时结果保留受限失败/过期历史，不能当current。job completed只表示工程任务结束，不能推出Matter.approved或法律审查已通过。
5. 重启恢复：遗留running parse/local mock仅在证明未外发且幂等副作用合同完整后可明确人工重试；未知模型/QCC按T08 dispatching/sent_unknown持久状态保持blocked/QUERY_STATE_UNKNOWN，不lease takeover重发。worker失权不能抹已发送账本，系统恢复采用明确可信技术入口。
6. 可选POST `/api/jobs/{job_id}/cancel`须按JobRow查案+CSRF/action；queued可以cancelled，running仅协作取消/等真实receipt，不能称请求已撤回或未知费用释放。GET轮询每次短事务读后退出；不sleep/long-poll期间持锁。用户离开页面不会自动取消/重发。

真实JobState是 `queued/running/completed/failed/cancelled/blocked`；页面中文“已完成”可对应completed，**API不能填succeeded**。RunStatus另有superseded；MatterStatus另有awaiting_lawyer/approved；PlanStatus/BillingState不能混成job成功。失败响应统一code/message/correlation_id/retryable；现ServiceError消息安全但仅英文通用串，UI按固定code中文解释，未知异常只安全generic+correlation，不发stack/路径/合同正文。

GET download：短事务授权并通过T09可信存储拿实际不可变bytes/hash与audience，退出Session后才流/返回；必要large file已授权安全句柄不能由client storage_ref打开。文件名统一server生成/安全Content-Disposition编码、Cache-Control:no-store；下载失败/撤销/陈旧正式批准不给有效正式件。浏览器只链接artifact UUID后端路由，绝无原件目录/static共享/外部公开链接。

## 原文定位、范围与escaping

- DOCX按version UUID、part_name、element_id、零基table/row/cell和exact quote hash定位，不全文查同句；start/end为Python字符[start,end)，当前T03整段start0/end=len。浏览器JS UTF-16长度和服务端Unicode字符数不同，包含emoji时应显示server切片/structure target，不能用JS.length重造补丁位置。
- PDF page是1基、bbox为有限float坐标；页面可先精确文字层+页/bbox说明，后续受控渲染候选未就绪时明确没有PDF视觉预览。缩放/旋转坐标映射须真实browser测试，不能无renderer宣称“点击已准确高亮原PDF”。
- quoted original、意见、文档名、案件title、客户偏好、part_name全部当text；html.escape(...,quote=True)，原生DOM使用textContent。拒绝innerHTML/markdown未经sanitization、用户动态模板、onclick string、CSS selector注入、script内未转义JSON；内部href仅canonical server UUID，外部法源URL不从模型生成且unsafe协议只显示文字。
- 页面/JSON/下载均no-store；CSRF及provider secret不入URL/localStorage/trace。撤销/401/403及时清空受控当前view和停止poll；不能承诺浏览器已被用户保存内容可远程撤回。
- 未读附件/unsupported/扫描/manual、已确认事实、current版本与实选法源/规则、QCC-off及receipt scope、mock limitations与18维状态都可见；“材料内审查继续”和“完整法律规则批准缺失”分别显示，不以绿色任务按钮覆盖真实范围。
