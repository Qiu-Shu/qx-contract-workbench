# T01 统一类型 配置与工程入口实施计划

> 执行采用 subagent-driven-development；此计划补充总计划中T01，不替代v2.0规格。已获用户“继续”授权，无需重复设计审批。

Goal: 建立后续服务共享的严格领域契约与离线工程入口，不伪造业务审查或生产批准。

Spec: 桌面v2.0规格§3、§5、§13 T01；实现字段及默认值以原文为准。

- [x] domain实现：`src/cn_contract/domain.py` 全部实体、辅助DTO与枚举；`validate_review(payload)->ReviewRun`；extra禁止，UTC、UUID和Decimal；四类与unknown分流；覆盖恰好C01–C18。
- [x] 配置实现：`config/defaults.json` 原样语义落盘；`load_settings(path)->Settings`；规范化hash匹配`0e4acba46c67b731cd9662d7b118217ddc55047ab69315961c7f78dfcfa9c887`；重复JSON键、extra和未批准真实服务开关拒绝。
- [x] 工程入口：`pyproject.toml` src布局；CLI只有help/config-validate/schema校验与生成；`scripts/verify_defaults.py`可以独立运行。未实现的review入口明确不支持。
- [x] schema：`ReviewRun.model_json_schema()`单一生成；字段与模型相同；schema本身不替代Pydantic跨字段业务校验。
- [x] 精确依赖：pydantic2.13.5 + pytest8.4.2及实际transitive版本/wheel哈希；Windows Python3.12；Scrapling可选独立锁；无真实网络业务。
- [x] 测试顺序：写功能缺失RED → 实跑 → 最小实现 → 目标GREEN → T00受影响全套 → 独立审阅修复与记录。

测试接口：`tests/unit/test_domain.py`覆盖类型、18维、extra、货币精度、时区与版本；`test_defaults.py`覆盖配置hash、约束与重复键；`test_cli.py`真实subprocess检查返回码和JSON输出。
