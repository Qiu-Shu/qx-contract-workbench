重大问题召回率按TP/(TP+FN)，精确率按TP/(TP+FP)计算；分母为0时记录unknown而非100%。应逐合同类型披露样本数、重大分母、误报/漏报原因和例外。锚点正确率需律师核原文和修订位置，修改正确率需核接受后的全文及数值/交叉条款关系；当前复杂对象和完整补丁后法律语义重审缺口须单列。规格95%召回、85%精确、99%锚点是待批准目标，当前实测值均未知。

每案费用保存官方账单、真实计费单位、金额Decimal、provider trace及对应单次幂等账本；发送或扣费未知时保留预留与次数，未对账不可填0或自动补发。模型使用量和外查费用按真实凭证分别记录，测试合成积分不换算真实货币。律师分钟由实际复核人开始/暂停/结束记录，说明资料确认、意见复核、改稿及签发各环节，不能把工程总运行秒数当人工时间。

编造法源、跨案泄漏、真实材料未批准外传、费用硬事件、错位修改和未经批准签发任一可信硬FAIL为NO_GO。总平均不得覆盖弱类、缺项或硬失败。缺证据保持BLOCKED，不将影子计划写成影子完成。最终测量只能由合法来源、当前范围和实际复核记录支持。
