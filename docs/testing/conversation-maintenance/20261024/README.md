## 本次实现

1. 默认Windows桌面普通文字的profile发送接通有界连续上下文：当前会话、同一绑定、已完成且确实保存了回答的文字问答，最多最近8轮/16条、32KiB；同时扣除当前请求预算和协议余量。只保留完整轮次，超大最近一轮不截断拼接，确认窗明确实际包含范围。
2. 历史从保存的用户消息及模型输出重建，按旧input_revision及时间截面验证；排除其他会话/绑定、未完成或未知请求、技能及资料工具轮。核对输出ID、run ID、scope及时间与数据库列一致。
3. profile存储族不变，增加严格v2模板和有界历史字段。空历史省略字段并沿v1模板，旧输入/wire兼容。许可摘要绑定全部历史和保存用途；预览、执行、历史读取及备份校验共用重建规则，恢复副本仍不可发请求。
4. 原生确认以纯文本展示实际历史与本次文字。历史只辅助理解回答，档案提案仍只能引用本次输入；不会将旧模型回答自动视为已核实事实。
5. 档案侧栏接通既有后端人工维护：12项字段、联系方式、材料状态、十进制金额/币种、UTC跟进时间、明确清空并保护空值。每次保存一项，无模型调用，默认仅修改档案；界面明确不同时改写接待登记。已关联接待版本仍纳入并发检查，后续自动提案不能覆盖人工值。
6. 当前/历史档案及恢复副本分别处理：历史、归档和恢复副本不可编辑。保存结果未知仅查原回执、不重发；确定拒绝释放pending；关闭、刷新及切换对话后的旧回调不写新对话状态。

兼容边界：当前接通连续历史的是默认桌面profile文字路径。无profile原生桥的旧浏览器/普通plain兼容路径及选片资料回答保持原有授权/输入范围，没有暗中附加历史。当前不扩展附件/技能自动建档、不将整份已有档案或资料库加入模型请求。

## 真实模型：一次虚构内容验证

结果：状态received、输出schema有效，回答包含上一轮虚构本金100元；输入531/输出17，共548 tokens；按配置保守单价估算USD0.0001797（不是供应商账单对账）。固定保存回执为unchanged；临时密钥删除。[无密钥结果](live-smoke.json)。配置价格和接口先核对[官方模型与价格](https://api-docs.deepseek.com/quick_start/pricing/)。

这是独立Mac进程里的API/后端集成验证；没有给普通HTTP服务器持久装配模型，也没有给Mac桌面新增凭据存储能力。原生系统持久化凭据仍按现有Windows实现。不是生产部署、安装版、真实客户材料或法律质量验收。
