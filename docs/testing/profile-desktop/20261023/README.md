## 失败与修正记录

- Native有效RED为44项中36失败；IPC初始缺入口及awaiting_input漏判有各自RED；最终均包含在366桌面回归。新档案用途严格拒绝awaiting_input活动任务。旧plain/context的相关行为不在本片顺带修改。
- 窗口RED29项中3失败；首次实现后1项为测试简化DOM未解析静态HTML文案，改为核对真实HTML后29项通过。IPC首轮畸形ACK测试预期码不符合既有停止后guard语义，记录保留，不当作产品缺陷。
- 首轮[实机失败](windows-01/report.json)发生在聊天页保存前；[最小HTTP失败测试](static-red.log)精准显示assistant-context.mjs的404。根因是旧静态白名单未加入已经被聊天入口导入的模块。只补白名单该名字，保持任意未列文件404，新增遍历实际入口导入链并核对HTTP状态/MIME/字节的回归。随后实机完整通过。
- 初轮完整Node与前端虽通过，仍未覆盖HTTP静态白名单；[初轮记录](initial-verification/verification.json)保留。最终修复和接待条件文案变化后重跑相关验证，最终输入与Windows输入完全相同。
