# 统一聊天直接模型闭环：2026-10-28 实测

实施依据：[本轮范围](../../../plans/2026-10-28-direct-model-mvp.md)。基线 `154ec10`，沿 `codex/contract-review-v2`；保留其他任务的界面、0.5.1 打包与合同模型对比改动。本记录仅包含独立虚构数据，不包含账户数据库、密钥或真实客户材料。

## 已实现

原生设置默认不勾选自动分析。用户明确选择模型及当前任务材料/问题/有界历史范围后，同一聊天发送会接续既有业务任务和单次模型账本；范围外仍走原生例外确认。材料事实保留来源与待核状态，不要求逐项勾选才能分析。保存、刷新历史与未知回执查询不会自动再发。

同任务追问最多复用 8 对、32 KiB 内的已成功问答；当前任务/会话/绑定不符、未完成、取消、未知执行不进入历史。当前问题与引用来源仍分开。Word 下载从保存成果生成可编辑草稿，不覆盖原合同；导出前后检查完整输入、回执、输出及事件账本。

客户纯文字追问承接唯一明确任务；存在多个可选任务时不按最近时间猜测。用户停止意图在原生授权等待阶段立即阻止前端继续，后端仍独立核验。案件转庭审仅复用可明确归属的同案原始用户陈述，保留更正与附件原文差异，不把先前模型推断作为已核实事实。

接待原话、补充及明确更正在原档案中连续保留，每条均有消息来源和待核标记；律师手工改写、清空或同值保存后不被自动覆盖。纯回复调整保持咨询事实不变，混合新增事实仍保留来源；汇总达到既有长度上限时保留原档案，并明确提示本次原话留在消息和档案历史中。

## 微信与交付边界

复用 [Tencent 官方 MIT 项目核验](../../../research/2026-10-28-personal-weixin-readiness.md)，新增独立连接探针，默认 OFFLINE。显式运行才获取二维码；令牌、回复上下文、游标只在内存。仅识别扫码本人、限定虚构文件名/大小/摘要、一次新口令；符合共同条件才回一条固定测试文字，未知发送不重试。没有真实扫码、下载解密或送达证据，尚未接统一业务任务。

普通本人微信助手会话无法读取所有好友原聊天。该能力边界已向用户说明，首版是否采用此入口仍待答复。不要把探针离线通过称为微信已接通。没有要求提供真实合同或客户资料。

源码 Electron 实测、冻结包回归、用户安装版、真实微信以及律师法律质量是独立验收项。旧 0.5.1 包的 15 项案件导出和 6 组统一 Mock 验证见[原记录](../../unified-mvp/20261028/README.md)，本轮安装以本页新增证据为准。WIN-PATH-02 / 原生 AV 未在本轮解决。
