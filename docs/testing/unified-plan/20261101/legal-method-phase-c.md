## 本片交付

刑事分析与辩护请求进入既有案件整理。同一任务内保存本次方法来源、摘要、程序阶段依据、逐字引文、证据分类、时间线、构成要件及策略候选；保存、回读、Word 和备份恢复共用校验。家事能力身份、四项入口、原有任务/费用/权限体系保留。

- 程序阶段只取当前消息独立声明并绑定来源，标记用户陈述未核验；缺失、疑问、引述、条件语句或冲突保持待确认。模型不能自改阶段。
- 真实性矛盾保留相反原文，不生成已排非决定。退赔专项限定量刑，构成要件及要件策略不得引用量刑证据。非审查起诉阶段不接受不起诉策略选项。
- 明确“只做证据分析、不要辩护策略”时，只登记分析方法；要件与策略数组必须为空。两种表达顺序均验证。
- 每项结构和引文校验不能证明自由文本法律推理正确；所有成果未核验、未签发。上游静态法条、配置指令及执行框架未进入运行链。

## 本机处理与历史边界

现有材料发送授权不是刑事脱敏证明。当前固定 synthetic-only-v1，仅接受登记合成附件，整个请求（含问题、历史和知识）只能使用本机模拟模型通道；真实模型供应商在排队/发送前阻断。

当前政策从已保存且经完整性检查的业务请求和附件快照派生，不依赖是否成功创建模型请求，也不回溯到旧 parent 时间。同任务普通跟进、同会话新任务复用材料、旧 parent 配当前 scope、首次被政策挡住后的跟进均不能丢失限制。普通措辞会提示明确“刑事分析”后继续原任务。真实脱敏批准链未接通前保留此保守交互。

显式刑事庭审及可引用的刑事上下文不得进入民事持衡 packet，返回尚未接入说明。普通旧协议继续兼容；旧受限刑事队列保留原输入字节，但按当前政策在发送前停止，费用记未发送。已保存成果回读不重写旧内容。
