# 法律方法第一批 B：合同组合分流

按[增量计划](../../../plans/2026-11-01-legal-method-phase-b.md)实施。状态：本批源码与受影响链路验证已完成；不代表安装版、法律质量或真实模型验收。

## 已实现的行为

新合同材料预览由后端生成 `contract-review-v1` 快照，按正文有限线索选取通用合同、保密协议、供应商合同方法。同一文件可组合方法，主协议和附件仍属于一个事项、一个模型请求和一个成果；补件产生新材料/成果版本，原成果与请求保持。

NDA 方法检查隐藏权利义务；供应商方法分列直接/间接损失、责任基数与例外。每个实际选中方法都须返回对应材料的分析条目，风险项包含精确引文、候选标准、差距、法律风险、商业摩擦、替换草稿和备选方案。方法来源、版本和摘要保存在请求与成果中；仅把本次选中方法文本加入原有模型请求，不安装上游框架。

引文与当前附件原文及字符范围逐字核验；知识片段不能充当合同原文。后端统一生成显示/导出正文，结算、回读、历史及恢复核对同一结构，拒绝正文或引文篡改。新协议不能降级为旧 text/citations；拒收时保留实际用量，不重发。

我方角色只接受当前用户明确表达；对方主体、假设、转述及不明确表达保留待确认，不从甲乙方位置推断。仓库已有 matter 政策批准链，但聊天流程尚未接入其核验证明；本片绿色关闭，候选标准不能作为律所已批准标准。草稿不自动签署、发送或修改原件。

SaaS、DPA、URL、部分可读、未读部分与解析质量由后端显示覆盖缺口。零正文附件保留目录但不要求不可能提供的分析；全部合同附件均无正文时发送前阻断。旧 C4 方法、旧字段省略与旧排队请求的字节保持兼容。

上游原作者和 Apache-2.0 许可见 [来源记录](../../../../sources/third-party-notices/claude-for-legal/README.md)。本机原始日志、执行命令/退出码、XML、差异和前后摘要位于 `.audit-local/legal-method-phase-b-20261101/`。
