## 变更

新增 `case-evidence-v3`，要求拟写正文自身说明已读范围，不把摘录未展示扩大成原件不存在，不借用其他事件或文件的日期。同时保留来源明确记载的空白、日期和事实，不能一概降格为未知。继续使用既有 `case-evidence-v1` 成果格式；未新增 Agent、数据库结构或外部依赖。

v1/v2 系统文本及方法摘要逐字保持。后端 DTO 和桌面允许值新增 v3；渲染明确保留 v2/v3 连续正文及独立复核区，旧 v2 不因默认版本升级而退回 v1 排版。合同、商标仍为 v2，刑事合成政策不变。

较长方法文本还暴露了输入容量边界：原反例请求为 132587 字节，完整持久化输入为 262983 字节，超过既有 262144 字节上限。`material_codec.prepare` 现在检查实际完整序列化 UTF-8 长度，复用 `MATERIAL_INPUT_TOO_LARGE`；异常发生在保存事务内，不放宽上限。原输出超限测试缩小输入夹具，并明确断言输入可保存、输出仍超限。
