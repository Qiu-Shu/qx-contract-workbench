## 实现范围

1. 在既有 DOCX 解析器中有界识别 Word 2010 的文字填充结构。合法但未使用的填充样式不再使整份样式文件失效；实际用于段落、文字或表格的扩展仍标可见性待核。未知、非法、歧义及错误命名空间仍保守处理，没有实现完整主题颜色或像素渲染。
2. 新增显式批量重新读取接口，复用现有认证、案件权限、CSRF/同源、后台队列、原件及追加式存储。绑定全部当前文件摘要和事实版本，执行前后重新核查；任何一份读取失败整批回滚。恢复核对副本和归档案件拒绝变更，重复请求保持幂等。
3. 原件及历史解析/事实保留。只有完整原文锚点未变的事实继续作为未确认候选；人工来源确认另核对绑定位置。旧审查、批准和导出失效，不能由重新确认事实而复活。
4. 沿用现有界面，先显示提取数量、缺口分类和版本原件入口，完整技术详情可展开。模型状态与文件读取状态分别说明。

业务 DTO仍在 `domain.py`，未增加产品依赖，未放宽可信解析、模型、QCC、外发或签发控制。
