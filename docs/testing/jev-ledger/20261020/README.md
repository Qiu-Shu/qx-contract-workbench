## 实现与边界

- 复用同一 `assistant_runs`，只增加辅助 attempt/receipt/decision 三表及独立小模块。旧 Main 表每个 run 只有一次调用且结算会结束主任务，不能拿来直接存 Jev 回执。没有新增调度队列、SDK或HTTP授权入口；主入口仅增加恢复/取消接线。
- 新版本 `assistant-judge-v1` 在固定旧 Main DDL 上追加结构；五个历史版本保持精确识别，隔离恢复和原生升级沿既有机制进行。原件、旧版资料、引用、账户及会话不由辅助模块重写。
- 独立政策绑定固定 TypeSafe 接收方、工作区、用户、登录会话、配置摘要、用途、请求ID、完整输入摘要、有效期和 Decimal 预留。主模型许可不授权 Jev；默认无政策不发出请求。首次执行后配置/撤权须在同一事件循环处理。
- 当前仅对完整普通文字做 primary_intent；显式技能跳过辅助。有附件或其他用途缺可靠来源映射时拒绝调用。Jev结果只产生内部待核建议，不确认事实，不写主任务的状态、供应商、模型或预算。
- 请求持久 claim 一次，网络等待不占数据库事务。收到的安全回执与是否采用建议分开；超时、取消、撤权或版本变化后仍保留已收到的使用量，但不采用建议。外部取消继续向上传播。重试同一 attempt 不重发。
- received/sent_unknown 保留预留，只有 not_sent 释放。预留是可信政策账目，不是供应商报价或已付款金额；缺失 usage 保持未知。启动/恢复只保守收尾，不自动联网；当前不支持重启后凭供应商账单追加结算。
- qxbak 保留完整辅助历史并使恢复副本只读；普通 cnbak 拒绝非空辅助历史。已安装0.4.1、真实材料、F盘法库、云端及GitHub未改动。
