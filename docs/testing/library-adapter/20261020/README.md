## 已验证的行为

- 复用既有导入、清洗、分段和索引；每次最多8个候选、每条最多1200字符，原文位置、版本、索引代际和片段身份可回查。目录、引述、重复条号与待核状态保留；受损索引不能提供正文、元数据或命中类别的权威结论。
- 重新核对筛选条件和规范化字符映射，标题/正文/元数据命中分开；跨片段命中不拼成一条规则，不可采用的候选计入omitted_hits。
- `source_match=record_quote_matched`只表示引用记录及摘录逐字/摘要相符。`registered_source_sha256`是整个源文件入库时登记的摘要；每次检索不重新扫描数GB CSV未被引用的记录。法律支持性与本案适用性始终unverified，不能据此自动确认事实或法条现行有效。
- 固定search/read_original两动作在文件读取前后重核账户会话、角色、案件/接待/工作区与草稿版本；读取途中撤权或切换后丢弃结果。读库期间不占业务库事务；不创建助手消息、运行、事件或模型任务。既有权限审计机制保留。
- 适配和权限代码独立于主入口，无新依赖、持久表、队列或进程。本片未测安装包、内存或启动收益，未更新0.4.1。
