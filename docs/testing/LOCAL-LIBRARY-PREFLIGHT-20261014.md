建议保留既有DuckDB/来源定位，中文全文索引独立管理；Meilisearch仅保留候选。统筹复核对以下推论作出修正，不能将原研究全文视为已采纳的事实：

- DuckDB FTS默认忽略规则不适于中文，但其规则可配置且可关闭词干处理，不能据默认值断言完全不能处理中文。是否适合本项目仍需实测。[官方参数与限制](https://duckdb.org/docs/current/core_extensions/full_text_search)
- SQLite FTS5支持增删改；外部内容须自行维护一致性，可用事务/触发器，不是每次变化都必须全量重建。跨库DuckDB原文不能直接充当SQLite外部内容表；无正文索引回查需由应用按稳定标识协调。[官方FTS5说明](https://sqlite.org/fts5.html)
- 中文词典切词不能保证所有两字子串召回；首批需实测短词与精确短语。Meilisearch官方确认中文词典分词，但本轮未安装或测试其Windows运行、性能或资源消耗。[语言支持](https://www.meilisearch.com/docs/resources/help/language)
- 十人内用户数量不决定百万条索引适配性；需要记录实际数据规模、查询、磁盘和内存。未对Typesense进行充分独立比较，不采纳原报告对它的排除判断。
