# 方法修订版内容复测口径

本轮按 `2026-11-02-skill-quality.md` 继续开发验证，使用与首轮相同的四组非刑事虚构材料。比较对象改为旧方法 v1 与当前方法 v2，各自重新生成；不把首轮通用 A 组与新方法直接混为同一实验。刑事不在本轮生成范围。

## 执行

- 工程修复及独立复核关闭后冻结两组完整请求、版本摘要与材料。每组用新的无历史生成代理，均只读本组请求，不读取评分说明、检查点或另一组结果。允许本机计算引用位置，记录为工具辅助 Codex 内容初评，不冒充工作台模型接口。
- 首先执行一轮四对。全部八份原始输出均保留，不挑选、不静默修复失败项；候选格式、逐字引文、支持关系与实用质量分别判断。
- 冻结原始结果后打乱 X/Y，保留原文、完整实质内容和结果摘要，去除方法身份元数据后供独立评审阅读。版式仍可能泄露组别，不能声称完全盲法。
- 使用首轮七维 0–4 分评分表，每项写材料位置或成果原句；主评与独评分别保存，不平均掩盖分歧。评分由 Codex 承担，WorkBuddy 可独立复核，无需等待律师参与开发评分。

## 从首轮分歧明确的口径

- 纯时间线或事实段落无需额外加入法条。法律维度评价是否越界、适用前提与待核范围是否恰当；4 分不代表做过法源检索，检索仍单列 NOT_RUN。不能仅因没有法条机械降为 3。
- 引用 4 分不仅要求字面与位置正确，还要求它支持所挂的断言；事实来源与限制/待核来源应可区分。相反来源列表越长不等于反方分析越好，需核对是否真正相反。
- 不因目录与某一方法模板不同而扣分；应看是否覆盖当前请求和材料中的实质问题。不因更长或更短直接扣分，需指出遗漏、重复或重排负担。
- 拟写文书应为可编辑实质段落，引用清单可另区，但不能丢失段落与依据的对应；正文占位符是否必要取决于该事实确实缺失，不能一概扣分。
- 合同同一原文可以支持不同风险；去重不能删除不同风险、条件或反方观点。商标初筛只评证据与因素，不奖励确定侵权结论。

一轮复测仅用于决定下一步修复；未达到重复观察要求，不据此作生产采用裁决。旧样本、规则、成绩与旧请求保持原样，新一轮另存，不回填未运行状态。
