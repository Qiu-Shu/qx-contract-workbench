## 已确认根因和修复

本机构建 Python 的 `ssl.py` 在创建 SSLContext 时读取相邻的 `codex-rejected-cas.pem`，原冻结包漏带该文件。实际冻结后端诊断在 `ssl.py:440` 抛出 FileNotFoundError，两个 HTTP 客户端均无法初始化；微信暂停，模型进入未知状态，环回请求数为 0。

提交 `5b8a4fc` 从实际构建时 `ssl.__file__` 的目录选取此可选文件，按原字节加入冻结包根目录；普通 Python 没有该文件时不添加。没有关闭 TLS 校验、修改证书策略或更换依赖。提交 `b999455` 将候选版本提升至 0.5.3，保留 0.5.2 安装器。

本机已安装 0.5.2 于 05:45:57 UTC 增补原始 906 字节资源，无重启、无数据库改写。SHA-256 与构建 Python 的原文件相同，见 [安装热修复记录](installed-hotfix.json)。随后产品内实际取得微信二维码，用户完成扫码；此时新消息仍被另一处格式兼容问题拦截，不能称微信收件已经通过。
