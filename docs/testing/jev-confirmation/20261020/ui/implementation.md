# CH-05D2 原生确认窗口：独立 Jev 选择

基线：a1ecd7e。仅改桌面原生批准窗口、它的 preload/页面和目标测试；没有改业务批准协调器、模型会话、后端、数据库、依赖或运行入口。

## 已实现

- 旧四字段详情保持 boolean 确认兼容；可选第五字段 `judge` 严格限定 `{available:boolean,max_total_usd:string|null}`。未提供第五字段时不展示辅助区。
- 辅助可用时预算必须为正十进制字符串，最多 12 位小数，最大 1000000；直接核验字符和整数部分，避免浮点舍入把 `1000000.000000000001` 误放行。不可用时预算只能为 null。
- 有辅助详情时只接收取消 false 或精确 `{main:true,judge:boolean}`。未读详情、跨窗口/框架、额外参数/字段、隐式真值、不可用时伪造辅助 true 均拒绝；旧窗口不接受新对象。
- 原生窗口复制本次显示快照（不保留外部传入 judge 对象引用），批准结果复制选择；没有增加 IPC 通道或 renderer 能力。
- 页面分别显示 DeepSeek 与 TypeSafe（api.typesafe.ai）、Jev 1.13.0、判断首个处理流程、同一完整文字且不含附件、内部待核建议。默认辅助未选；不可用时禁用，并说明本次不会发送 TypeSafe，不影响主模型确认。
- 辅助预算明确为本机预留，不是供应商收费上限，实际费用尚未核对。主字段用“程序预算”取代容易误解的“费用上限”。
- 保留原生隔离会话、全网络封锁、精确窗口来源、取消焦点且不滚动、Escape、页面离开清空、失效拒绝与迟到响应防护。无 innerHTML，无联网字体或新依赖。
- 沿用 Impeccable Operate 的既有中文排版/克制强调色；辅助窗口默认高 700、旧窗口 540，最小高仍 540。实际显示缩放/截图由主代理验收，未自行运行 GUI。
