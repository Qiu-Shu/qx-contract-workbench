## 服务与边界

`build_fact_candidates(parsed, extraction, *, matter_id, version, actor, db)` 中 version 是目标事实版本 current+1，parsed.version_id 是文档 UUID。严格接收 `facts` 列表；每条仅 field、typed_value、unit、provenance_type、anchor_ids、receipt_ids，typed_value 仅七种 kind/value。服务端生成事实 ID，永远 unconfirmed；冲突候选和列表顺序保留。document 锚点必须属于本案实际文档，整个输入解析快照先与已存结果全等，再通过 T03 的纯适配分发器从 T02 授权读取的原件重算全部 ParseResult。已存 parse 本身不是原文信任根。external/receipt 在 T08 前明确 NOT_SUPPORTED。build 只返回列表，不写事实快照、解析快照或立场。

`require_position(matter_id, *, actor, db)` 在立场 None 时 FACTS_UNCONFIRMED，不把合同标题、甲乙方或候选字段改成 Matter.position。

`confirm_facts(matter_id, version, decisions, actor, *, db)` 中 version 是期望当前版本。真实 handling/reviewing 会话与成员权限、当前版本、完整来源和所有决定先预检；空/重复/未知决定、旧版本、值种类转换及 confirmed/rejected 借决定改值被拒绝。corrected 保留 field/unit/来源/锚点，整份 facts 顺序进入 +1；未决定事实历史确认人和时间不改。实际用户与 UTC 时间由服务器设置。FactSnapshot hash 的 sort_keys 只排序字典键，列表顺序参与哈希。

快照保存、受保护决定、旧批准 stale、制品 superseded 和审计在一个服务保存点内。真实 before_insert 故障测试覆盖调用者捕获服务错误、继续提交的情况；不是仅依赖外层 context 回滚。数据库串行下两个旧版本请求只有一个推进。决定 reason 只保存于受保护 append-only 技术表，公开 audit 只保留 hash。

`initialize_storage(database)` 是明确的服务启动初始化，无 import-time 数据库或默认账户；使用既有 Base、外键与 SQLite UPDATE/DELETE 拒绝触发器，初始化不是客户端接口。业务调用 join 既有事务，不自行 commit。新增表 fact_decisions、party_snapshots、party_decisions 只追加；SQL UPDATE/DELETE 实测拒绝。

`calculate_expression(expr, values, *, inputs=None, rounding=None, assumptions=(), matter_id=None, fact_version=None, actor=None, db=None)` 仅解释唯一 DTO 白名单 AST；无字符串解析、call、attribute、eval/exec。明确上限：128 AST 节点、32 深度、128 输入 Decimal 位数/指数、512 工作精度、整数幂 [-100,100]、有界输出；除 0、0**0、未知/多余变量、float、非有限值拒绝。独立 Decimal Context 固定中间舍入与 traps，不受调用者全局 context 影响、不修改全局 context；有限精度及末尾舍入限制记录于 assumptions。quantum 是真正步长，实测 1.03 按 0.05 舍入为 1.05；完整式算完才舍入。

输入 metadata 名称/值精确对应 values；fact_ids 必须来自授权本案当前或明确指定的既存确认快照，逐项核验 confirmed/corrected、Decimal 值、单位和版本，记录所用版本/hash。不同单位相加拒绝；含单位乘除幂需明确 assumptions 说明口径。ratio 转 percent 必须最终显式 ×100；percent 转 ratio 显式 ÷100；仅重标单位拒绝。未绑定全部事实的数学输出明确限制不能直接作为合同结论。复利独立期望精确值 `0.268241794562545318301696`，八位结果 `0.26824179`；月 2%/12 期/按月复利数学口径由调用者明确，不宣称合法性或统一法律阈值。

`payment_base_facts` 返回已确认前月实际付款金额及期间两个原始 Fact；`payment_base_input` 是数字便捷入口，调用审查时还须保留前述期间证据。仅 annual_fee、期间缺失、冲突或未确认时 FACTS_UNCONFIRMED，绝不 annual_fee/12；实际 0 元可返回精确 0。`notice_direction` 区分客户不续约期限和供应商涨价通知；仅接受明确自然日口径并给事实方向观察，不输出风险排名、法域覆盖或法律上限。

`resolve_party(candidates, decision, *, matter_id, role, name_raw, actor, db, party_id=None)` 先无决定登记服务端 party ID 与技术 revision，之后才能在同案件/角色/原名当前 evidence 内选择。无/单候选无决定 unresolved，多候选 ambiguous；同名不同代码或同代码不同名不合并，不按排名猜测。决定需要真实确认权限、actual user 与非空 reason；重复、未知、跨案、历史候选或变更上下文拒绝。候选 UUID 永远不是企业 entity UUID，Party.entity_id 保持 None。主体变化统一 party_changed 审计并复用 T02 失效机制，没有任何外部请求。
