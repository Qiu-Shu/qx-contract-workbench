## 实现与验收边界

实际 `mcp/mcp-types==2.2.0`、`httpx2/httpcore2==2.13.1`；真实安装版 ClientSession + streamable_http_client 两元 tuple + snake_case initialize/list_tools/call_tool。测试内部独立 MCPServer/uvicorn thread 实际监听 `127.0.0.1:动态端口/mcp`，完整固定 origin/path allowlist，POST、JSON response、stateless StreamableHTTP；finally bounded shutdown。没有手写协议、v1 三元 tuple、stdio/subprocess、SSE 任意端点、外网或 QCC 请求。

Mock 固定登记、实际管理员+服务端 grant 管理目录/价格/审批，普通本案律师按真实 session/成员权限使用；管理员没有默认正文权限。客户端批准人、价格、schema/provider/endpoint 字段不形成授权。完整 input/output schema hash 及价格快照变化使旧绑定失效；调用前实际发现新目录也能使旧 binding disabled，未知工具或 schema 外部引用零业务 call。JSON Schema 的 `$ref/$dynamicRef/$recursiveRef/$id` 非内部片段拒绝，本地 validator 使用无远程 retrieve 的 Registry；未approved辅助地址也不允许请求。

字面和合法 Unicode 转义 key/value 密钥反射在 SDK 解码/日志前拒绝。body 限1MiB、深度32、节点20k、duplicate/nonfinite拒绝。日志不含参数/正文/异常链；秘密来自合成 opaque ref 的私有 server map，不读取任意文件/环境。未知状态不能变成无风险。SUCCESS 的 partial pages 仍保留范围缺口；is_error 即使 structured=None 也为 FAILED；无确定发送结果为 SENT_UNKNOWN。本期 billing_known/charged=0 只表示合成固定零成本，不冒充真实价格/账单。

保护 raw 保存安全实际 SDK result 和 call HTTP JSON `wire_response`；SDK 或本地输出校验失败不覆写收到的响应。raw hash 是完整 canonical payload SHA，非 wire bytes SHA。secret guard/未收到响应只有明确标记的 safe_error_summary。raw+invoke 记录 savepoint 原子追加、SQL trigger 拒绝改删。调用后失权可留 server receipt，但拒绝向旧 session 返回 raw。caller catch+commit 方能保存失败历史；caller rollback 不保证未来外部账单收据，此事项归 T08/T12。

规格 DTO 接口与后台技术引用的兼容映射、T08 read-binding/current-price/endpoint/approval 契约详见 [T07-provider-interfaces](../reuse/T07-provider-interfaces.md)。没有修改 domain DTO/schema/defaults。没有启用 G05 备用 CLI。
