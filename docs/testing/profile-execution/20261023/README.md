## 本轮修复与失败证据

执行前保留缺入口RED及空账本孤立事件RED。实测发现SQLAlchemy嵌套上下文在权限拒绝rollback后阻止新审计事务，已改显式savepoint生命周期；调用者捕获最终账本故障后提交外层事务也没有半档案。历史DTO初版排序误把普通记录升级为档案，已修并保留旧格式往返测试。
