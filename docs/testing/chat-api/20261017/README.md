# 对话接口、取消与事件续读

2026-10-17；基线e7618bb。现有架构和assistant-v1数据库结构保持；新增模块只消费已验证的对话服务。独立合成材料，不接主模型、Jev或真实资料。

## 实现范围

`web/assistant.py`承接对话创建／列表／读取、草稿保存、发送登记、运行读取／取消、事件续读和技能目录。app仅增加两行装配。复用现有认证、同源、CSRF和严格JSON；读请求体前验证身份与归属、释放事务，写入前再次核验。技能目录如实标明对话执行尚未接入，发送返回持久queued，不制造模型答复。

列表每页最多扫描50条本工作区／本人记录，再按当前关联权限过滤，不读取全部消息。页内记录被撤权后可以返回空页和继续游标。事件每批最多100条，校验前缀及窗口序列；断线续读不会创建新任务。排队／等待输入的任务立即取消，执行中只记录取消请求；不能据此声称外部调用未计费。状态与事件同保存点，重复取消不重复追加。

每批事件重新创建短会话复核身份与作用域；提交并关闭后才发送或等待。15秒是轮询窗口，到期后不发下一帧；它不是网络连接或数据库读取的硬耗时上限。既有SQLite忙等待与网络回压可能延长连接，不能把单次15秒busy timeout当完整操作上限。恢复副本只增加明确的只读路由，写操作仍被中间件与服务共同阻断。
