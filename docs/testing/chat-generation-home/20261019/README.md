# CH-04C：首页发送、历史回复与原文定位

2026-10-19，基线 `f218f44`，沿 `codex/contract-review-v2` 增量实施。本片已完成下述工程验证；真实模型、安装交付和法律质量是另外的状态。

## 实现结果

首页现可消费 CH-04B 的受控生成接口：保存当前文字后重新核对权限、版本与摘要，明确发送只创建一个请求；网络结果未知时只查原请求，不自动重发。等待期间的新输入保留，切换或撤权后的迟到结果不会进入当前页面。Enter 发送、Shift+Enter 换行及中文选字保护继续使用原生输入控件。

历史回复按对应律师输入排列，刷新或再次发送后仍可读取；引用定位到本次输入。显示“模型生成／内部草稿／待核对”，保留估算、未知、确认未发送三种费用含义。纯文本渲染保留换行，模型返回的 HTML 不执行。本片还没有材料引用或法条引用生成，不将消息原文定位称为完整法律引用闭环。

新增独立 `assistant-generation.mjs` 和历史读取服务；主应用只增加一个静态模块白名单项，HTTP 保持薄装配，DTO 仍集中在 domain。无新增运行依赖、字体、动画或前端框架。[模块尺寸记录](module-metrics.json)用于说明代码分工，不据此宣称安装包或启动占用已经减少。

默认运行时仍为空。生产入口未配置时不能发送；技能选择和含 DOCX 的对话仍准确提示未支持，不能用普通文字生成假冒完成对应业务。
