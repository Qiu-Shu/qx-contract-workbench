## 本片变化

在既有对话运行中保存固定工具事件，执行 `legal_library.search` 或 `legal_library.read_original` 后，以同一短事务保存成功回执与有序引用快照。引用有服务器 UUID，不能把模型自填的引用 JSON 或内容摘要当作访问凭证。原文复验只接受同一运行较早生成的已保存引用；每次新复验产生新快照，旧快照不覆盖。

同一调用 ID 和请求返回原事件；固定事件执行后重放返回原回执，不重复读取法库。同一运行最多 8 个逻辑工具事件，失败或未完成事件也计入；并发最多提交一份成功结果，但不承诺物理只读 I/O 恰好一次。执行前后检查当前会话、权限、作用域、草稿版本、取消和恢复隔离；文件读取在业务数据库事务之外。

新增 `assistant-library-v1` 的两张不可变表，固定 Judge 历史结构，复用现有初始化、逐版本升级及加密备份恢复机制。qxbak 保存历史快照并在恢复时撤销旧会话、隔离运行；没有外部法库也能按当前权限读取历史。旧 cnbak 继续拒绝此类助手记录。未完成工具事件、来源依赖、内部摘要、顺序、历史身份和范围也进入归档校验，损坏恢复不发布目标。

实现放在独立的调用、快照编解码、引用身份、schema 与完整性模块，DTO 仍统一位于 domain.py。未扩大主 HTTP/桌面入口职责，没有新依赖或后台服务。本片未测安装包、启动或进程资源，不能把模块拆分等同于资源验收。
