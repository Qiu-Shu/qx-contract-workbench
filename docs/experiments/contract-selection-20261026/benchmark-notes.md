## 判断约定

- supported：所断言的事实由现有文本直接支持，或由明示数字进行唯一、透明的算术推导而得出。
- refuted：现有文本给出与断言冲突的明确条件、数字、限制、例外或材料状态。不能只因找不到一句话就判 refuted。
- not_stated：现有材料不足以确认或否定断言中的具体事实、数字、要求或期限。可能已有邻近义务，但不得把该义务扩写成缺失要求。
- 所有判定只针对所给文本表达的内容，不评价条款效力、现实履行情况或外部法律结论。
- required 是默认可接受的完整相关证据集合；optional 是允许补充的相关锚点。可选字段 alternatives 为列表的列表，其中每个列表均是一组可独立支持结论的替代锚点集合；满足 required 或任意一个 alternatives 集合均视为满足证据覆盖，不能要求同时满足全部集合。引用必须同时匹配案例中的 ID 与该 ID 的完整 quote，不得伪造“未约定”引文。自然语言 explanation 只核对语义，不与 gold 的 rationale 做字符串相等判断。
- 对重复句不能只按 quote 字符串查找；必须保留所在章节的锚点 ID 和必要上下文。
- 已对九个核对项补充明确等价的 alternatives，原有 required、optional 和 rationale 均保留。事实正确、引用完整、证据覆盖应分项报告；没有列出的潜在等价组合如需人工裁决，应单列记录，不事后静默改动已冻结评分规则。
- 按共同输出协议，正确的 not_stated 允许 citations 为空；examined_anchor_ids 仍必须覆盖本例全部锚点，explanation 仍须独立语义审阅，说明缺少的具体事实或条件。not_stated 的 required 仅表示默认相关上下文，不是硬性引用要求，更不是对缺失事实的正面证据；无需逐项添加空 alternatives。提供引用时，只接受对应原文和相关上下文，不能为填满 required 强迫引用无关条款。
- 每例恰好三个 verdict 各一项是本次小型基准的平衡设计，可能被模型推测；不要把这一分布写入候选提示词。不能据本基准推断真实业务中的自然分布或生产可靠性。

模型输出协议由调用方实现：examined_anchor_ids 应覆盖该例全部锚点；formal_signoff 必须是 false；legal_status 必须是 not_verified；每个 check 提供 id、verdict、citations（含 id 和完整原文 quote）及简短 explanation。以上为验收数据协议，不是另建的候选提示词。
