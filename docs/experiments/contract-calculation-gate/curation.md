# 独立虚构原文计算计划整理记录

日期：2026-10-26。仅以 benchmark-inputs.json 和 validation-inputs.json 为案件资料；未读取模型答案、评分答案、已选提示词或 API 凭据，未联网或调用付费服务。

## 边界

此计划为工程人工整理的可信输入。中文数字、计价口径、单位、公式及分类规则均由整理者从原文选择并解释；片段存在性与案例摘要一致性只证明计划绑定这些文字，不能证明文字到数值、公式或法律含义的语义映射自动正确。使用前仍需独立审核人工映射。

计划不含答案标签，保留整条原断言和全部必要比较；n12/q2 必须同时检查两个金额。全部 inputs 的 fact_ids 为空，现有计算器明确返回未绑定全部已确认事实的限制，不能据此正式签发。

## 覆盖与证据

4 个案例、8 条断言、9 个比较。n17/q1/q2/q3、n18/q1/q4、n20/q1/q2 及 n12/q2；非算术事实、实际履行证明和无法从原文金额推出的外部报价不纳入。n18/q4 严格使用 gt；裂纹分类 a3 与交接记录 a4 是必要规则证据。n20 时段单价不再乘两小时；最终场租使用 a2/a3，剩余场租追加 a4，不要求与本次场租计算无关的另加服务证据。

数量暂以 ratio 表示无量纲计数，逐项 assumptions 说明业务单位；CNY 单价输入经计数相乘得到 CNY 总价。percent 输入均先显式除以 100；percent 输出均在根节点乘 100。原文数字均为有来源的变量；literal 仅用数学常数 1、100。

## 验证记录

- 独立 Decimal 临时复算：第一次命令因 PowerShell 引号转义失败，退出码 1；改为标准输入脚本后退出码 0，完成 8 类数值复算。
- 本整理脚本：验证 4 个 fingerprint 与规范化 JSON SHA256 一致、8 条 claim_quote 完整一致、9 个比较结构/变量绑定/原文片段/目标片段/证据覆盖/受限 AST，并执行既有 Decimal 计算器；全部完成后才写出两个交付文件；该次命令退出码 0。
- 9 次计算均返回未绑定全部已确认事实的限制。尚未执行主代理正在编写的门禁集成测试，本记录不声称生产验收或自动语义验证完成。
