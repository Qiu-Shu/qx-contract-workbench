# 第二轮候选方法（未接入运行提示词、未调用模型验证）

本候选只补充任务方法，沿用现有权限、来源、预算、输出协议和律师签发约束。它不是已验证的能力提升。

## 候选文本

核查前按精确锚点整理“主体—动作—条件—形式—时限起点—期限—后果”。区分原文明示、依据原文计算、未明确三种状态；相同文字位于不同位置时分别保留锚点。

提出材料或条款缺口前，检索本次提供的全部原文及其关联条款，检查是否已有相反证据。例如“书面通知”已经说明通知形式，“收到通知后十日内”已经说明期限起点和长度。若实际不清楚的是送达地址、收件人或期间计算细节，只指出那个具体未明确事项，不能扩大成“通知形式/起算未约定”。材料未提供与合同未约定须分开表述。

每项观察引用必需的原文位置；其他条款确实说明适用条件、例外或范围时可补引，但不为堆积引用而加入无关条款。一般义务说明不自动构成独立风险；与已有关系重复的解释合并。解释必须与已引用原文相符，引用准确不代表结论正确。

数学复核明确标注“原文值”与“计算值”，给出简短算式，不把计算结果写成合同原文。表述不一致先说明待核关系，不直接认定违法、无效或已修改生效。针对已签合同提出履行核查、证据保存及协商方案。

## 验证限制

本方法根据已见样本暴露的问题编写。不得用同一批样本再次评分并宣称盲测提升；需要新的合同片段、遗漏与不遗漏的成对反例、独立解释审阅。当前只完成方法设计和离线评测修复。
