# 安全运行说明（T12，受限本机开发）

本说明适用于独立虚构数据演示。生产批准仍缺失；不得上传真实合同、启用真实模型或企查查、付费或接受第三方协议。配置默认来自 `config/defaults.json`，QCC 默认关闭、模型仅 mock、单个 worker。T10 的浏览器结果和 T11 的 84 项结果都有其原始源范围与时间；新增 T12 后不能直接把旧评测称为当前全部能力通过。

## 出站边界

`ops.egress.check_egress` 只接受服务器实际 T07 登记、当前成员和会话有效的独立虚构 `127.0.0.1:<port>/mcp`。客户端的域名、地域标签、地址和重定向声明不能授权出站。实际 MCP SDK 使用固定数值 loopback、精确 URL、无环境代理、无重定向、无业务自动重试的已有 transport；Factory 接点在发送前重验登记和持久账本。真实 HTTPS、地域证明、供应商许可、账户和数据政策均未批准，因此此接口拒绝真实目的地。

恢复数据库的 `ops_restore_fences` 会永久阻断当前 worker 领取、任务创建、直接 QCC gateway、发送标记及 Factory；新登录不会解除隔离。应用层门禁不等同操作系统网络沙箱。全机抓包、WFP/AppContainer、进程 CPU/内存约束、国内 host 与生产 HTTPS 均没有本轮实际部署证据，保持 NOT_RUN / NOT_IMPLEMENTED / BLOCKED。不要通过修改全机防火墙或自签证书补写成功记录。

## 密钥和待发布材料

业务与运维配置只存引用；前端、命令行、Git 和公开日志不得出现密钥。`SyntheticKeyStore` 只提供显式传入的公开虚构测试字节，不生成、查找或管理真实凭据，不从环境变量或文件路径兜底解析密钥。生产密钥托管、权限分离和轮换政策仍未批准。

`scan_candidates` 扫指定候选 bytes，包含受大小、成员数和压缩比限制的 DOCX/ZIP 内部部件；异常归档不能放行。检测结果仅有候选标识和原因，敏感文件名改为脱敏序号。`scan_staged` 读取真实 Git index blobs，工作树中删除秘密不能掩盖已暂存内容。使用明显虚构 canary 的检测属于工程验证，不证明所有私人资料都能被 pattern 识别；其他敏感分类及人工审查仍是待批准要求。不扫描桌面、知识库或其他项目的私人材料。

## 恢复隔离与历史制品

恢复前使用原始 SQLite connection 验证完整物理 schema、约束、索引、不可变触发器、integrity、FK、表行数量及摘要，不允许先 `create_all` 自动补缺。恢复只到新目录；所有旧会话撤销、queued/running 任务隔离，发送不确定状态保留积分和调用次数。历史批准、审计、原件、事实、模型原始输出、规则和 run 记录不覆盖。未知高水位不能因为备份合法而成为当前可信发送证明。

历史绝对制品引用通过数据库内不可变的 logical ref/hash/record 映射指向恢复目录，继续核验文件 hash、单链接与 reparse 边界。`read_historical_artifact` 是授权后的历史对账读取，不能验证当前修订批准或正式签发。当前 patch、bundle、下载与新 patch 批准受恢复隔离门禁。测试必须在原存储暂不可用时读取恢复目录，防止误用旧路径。

发现 secret、归档错误、源材料 hash 不一致或未知发送时，停止本次操作并保留安全错误码和受保护原始证据。不得清空账本、修改历史批准或自动重发。生产解隔离还需要独立最新外部发送/撤销高水位和真实批准；本轮没有实现可由客户端开启的解隔离接口。
