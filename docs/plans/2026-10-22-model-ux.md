# 对话页模型 UX 小片执行合同（2026-10-22）

基线：`8c609ac`（codex/contract-review-v2，B3 回执已核对）。本片的界面与行为变更均来自产品所有者（宋萌律师）当日直接指令：①发送按钮灰色问题排查；②「切换模型」按钮放在对话页「保存草稿」左面；③取消每次运行都要手动「配置本次运行」的安全设定。

## 1. 排查结论（灰色按钮）

- 模型"启用"是后端进程内存态（registry/configure 不持久化），重启进程即回到"本次运行未配置"；凭据文件持久保存。
- 发送按钮 gating：需要已保存草稿 + capability 状态 ready/unapproved/budget_exhausted（原生确认窗存在时）；capability 在保存草稿后由页面自动拉取（coordinateGeneration 防抖调度），配置模型后页面未刷新时会持有旧状态。
- 既有缓解：设置页「返回工作台」会整页重载；本片再加窗口焦点回来时自动重拉 capability（`window focus → refreshGeneration`），覆盖其余路径。

## 2. 变更设计

### 2.1 自动配置（取消每次手动配置，所有者明确要求的安全姿态变更）

- `desktop-settings.json` 新增可选键 `model`（严格校验：仅 `deepseek-flash`/`deepseek-v4-pro`，加载校验同步加宽）。
- 设置页配置成功 → 持久化所选模型；显式「停用」→ 清除持久化；**替换/移除密钥不清除**（下次启动用新密钥恢复所选模型；密钥缺失时自动配置安静失败，设置页仍是人工兜底）。
- `startBackend` 就绪后 `await autoConfigureModel`：有持久化选择则用本机已存密钥自动 configure；失败安静回退为未配置。
- 恢复副本（recovered/）工作区永远不自动配置（getBackend 已为 null，天然拒绝）。
- Jev 辅助判断不自动配置（真实预算未配置，保持关闭）。
- **不变的安全闸门**：每次发送仍走桌面原生确认窗逐次核对全文/接收方/预算上限；授权 lease 单次语义、会话绑定、有效期 120 秒均不变；密钥仍只存 OS 保护存储，不进 Git、不进设置文件。

### 2.2 对话页切换模型按钮

- 新桌面模块 `model-bridge.cjs`：`registerAssistantModelBridge`（`desktop:assistant-model-status` / `desktop:assistant-model-switch` 两 IPC，仅对话页主 frame、`state.mode==='ready'`、非恢复副本可调用）+ `autoConfigureModel`。
- 切换语义：configured → 两模型互切并持久化；未配置 → `UNCONFIGURED`（前端提示走菜单设置页）；失败不回写设置。
- preload `desktopAssistant` 增加 `modelStatus`/`modelSwitch`；对话页 `.save-actions` 内「保存草稿」左侧新增 `#switch-model`（无桌面桥时保持 hidden；按钮文案显示当前模型名）。
- 切换成功后前端自动 `refreshGeneration()`（两模型价格不同，capability 需重算）。
