- 独立 JudgePolicy、attempt/receipt/decision DTO 与模块；固定 TypeSafe 接收方、会话、输入摘要、用途、有效期和 Decimal 预算。普通文字 primary_intent 首片完整保留原话；尚无可靠来源映射的材料分类和推广稿用途保持拒绝。显式技能无需辅助。
- reserve、一次 claim、事务外 judge、settle、recover；已收到回执与可采用建议分别保存。主模型许可不授权 Jev；默认无许可不发出请求。取消、作用域/材料/配置/授权变化后不可采用，可能已发送仍保留未知费用占用。未知用量不记零，不自动重试。只明确未发出时释放预留。
- 费用字段是可信政策预留与占用，不是供应商结算承诺或编造价格；真实账号、收费调用、页面/原生设置和主生成前置接线仍待后续。本片提供可独立执行的受信任后端调用链。
- 独立三表保存不可变输入/政策/配置、回执和采用记录；同一 run/purpose 唯一。新增 schema 版本，固定旧 Main schema，复用现有逐步升级、旧备份识别、只读恢复 fence、所有权和原件完整性检查。
- 启动/恢复仅收尾历史 reserved/sending，不启动网络、不结束主运行；取消未发送辅助时释放预留，不影响主模型历史。辅助不写 selected_provider/model/budget_json、不独自完成/失败主运行。

## 后续接线契约

`JudgeRuntime` 只装配固定 JevProvider 与独立 JudgePolicy；首次执行后配置、撤销及批准须在同一事件循环进行。不能沿用主模型授权，也不能让页面提交 policy 即获得批准。策略保存接收方、用户和登录会话、配置摘要，以及每项用途/请求ID/完整输入摘要；本片预留数额为策略参数，后续原生确认须如实说明，不显示为供应商已收费用。

`request_for_run` 从当前持久消息建立完整请求；`reserve` 保存不可变输入并检查政策与累计额度；`execute_attempt` 只执行一次持久 claim，HTTP 期间不持有数据库事务；`read_attempt` 按当前用户权限读取内部待核建议。已点选技能直接跳过，不为辅助判断删减原话；当前有附件或用途没有可靠来源映射时拒绝进入此链。现有主生成管理器尚未调用这些接口，后续需在同一个 run 内增加可跳过的辅助阶段，不能新增第二队列。

历史 receipt 与 decision 是两种记录。received/sent_unknown 保留预留，not_sent 才释放；取消/过期/撤权/版本变化后允许保留安全回执但不采用建议。启动或恢复仅确定未完成记录的保守状态，不重发。该不可变历史尚不支持重启后凭供应商外部账单追补结算；这是后续独立功能，不能把当前恢复称为最终对账。

后续窗口和主流程接线仍沿 CH-05 继续；材料分类与运营风险另外绑定实际材料/成果版本，不能将 primary_intent 的来源假设直接套用到其他用途。备份必须使用 qxbak 保存完整对话历史，恢复副本仍只读；普通 cnbak 不接纳非空辅助历史。
