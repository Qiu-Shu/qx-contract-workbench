# CH-04D：桌面主模型凭据的本机保护入口

## 已有基线与本片边界

接续 `f433493` 和 `2026-10-19-post-home-readiness.md`，复用现有 Electron 设置页、主进程发送者检查和系统加密接口；不改框架、不另建任务队列。上一片首页发送及历史已经完成，本片不重跑无关后端全套。

主模型配置与外发授权尚未贯通。当前 MainModelRuntime 持有单个供应商和绑定用户/工作区/配置摘要/原文摘要的 policy；不能用保存密钥顺手替换全局 policy。本片先完成独立的原生凭据生命周期，下一片再建立配置与每次发送的授权接口。保存密钥不启用模型、不授权外发、不产生费用，界面明确说明。

## 实施契约

- 主进程新增独立小模块，使用已安装 Electron 44.8.0 的 safeStorage 异步接口；Windows 不支持系统保护时关闭保存。系统保护防止其他 Windows 用户直接解密，不宣称能抵御同一 Windows 用户下的其他进程。
- 只存 DeepSeek 一项固定用途凭据，放在桌面数据目录的独立凭据子目录；不放入 desktop-settings.json、业务工作区、备份、Git 或普通日志。不扫描用户已有密钥。
- 主进程 API 仅返回未配置、已保存、损坏/不可用状态；从不返回密钥。保存、替换、移除按顺序执行；异常信息使用固定文案，不转发加解密或文件错误详情。写入失败保留旧凭据；写入采用同目录临时密文和替换，检查路径祖先、符号链接及硬链接，限制文件大小。
- 设置页通过现有应用菜单进入。仅原设置页的主框架、原窗口可调用专用 IPC，后端页面、其他 frame、其他窗口被拒绝。设置页提供密码输入、保存/替换、移除、状态和返回工作台；保存后清空输入，切换页面也清空。保存不会向 HTTP 后端传密钥。
- 沿用既有样式、键盘与可读性，不新增依赖；显式更新桌面打包文件清单。既有安装版与真实库保持原状。

## 验证与交付

1. 模块单测覆盖空状态、保存/替换/移除、重启读取、加密失败保留旧值、损坏/超大文件、链接/路径拒绝、并发操作和固定错误；合成标记不得出现在存储文件、返回结果或错误中。
2. 设置页与权限测试覆盖可信/非可信发送者，重复提交、异常恢复、输入清空、离开状态；普通页面不能读取或修改凭据。
3. 在隔离临时桌面目录用实际 Electron/Windows 系统加密运行合成凭据往返及重启验证，实际加载新设置界面并截图检查；禁止真实 API 调用。运行包清单检查，相关既有桌面测试回归。
4. 独立复核（WorkBuddy 当轮可连接则委托限定源文件；不可连接不以历史回执代替）、保存命令/数量/退出码/输入摘要，更新 TASK_STATUS 后本地提交。

官方依据：https://www.electronjs.org/docs/latest/api/safe-storage （2026-10-19 阅读）；实际安装 electron.d.ts 已核对存在 isAsyncEncryptionAvailable/encryptStringAsync/decryptStringAsync。本片不自动处理未经验证的密钥轮换，也不把系统加密成功当作模型联网成功。
