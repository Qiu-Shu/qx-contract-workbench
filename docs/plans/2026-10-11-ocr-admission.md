# QX08 第一增量：昂贵工作前准入

基线 ad7c99781892eaa88acc82f1c06701be8de258d6。沿已批准整改路线，保留现有实现。

范围：所有公开 OCR 服务调用先获得进程内非阻塞锁与 Windows 跨进程文件锁，再核验资产、准备位图和运行隔离 worker。忙碌请求返回 OCR_BUSY；错误路径释放两层锁。既有 bytes/metadata 入口保持兼容，PDF 入口通过延迟准备回调进入同一受控入口。授权、幂等回放、保存前版本/权限重检保持原位。不增加跳过校验参数或调用方提供的准入令牌。

验证接口：run_ocr_page、predict_page，以及原有 page-ocr HTTP 路由。先通过并发公开调用重现重复核验，再完成线程/独立进程竞争、渲染前拒绝、失败后重试和原有授权路由回归。普通测试只用虚构材料和替身隔离 worker；不得把这些计为实际模型推理。记录每个命令、退出码、数量；完成双轴独立审阅后冻结源码运行一次完整套件。

本增量不修改核验强度、不缓存模型许可、不更改渲染质量、不删除历史工作目录。全链路真实分段性能、模型副本配额/治理、PDF 解码全过程隔离仍属于 QX08 后续，不能据本增量声称 QX08 或生产完成。
