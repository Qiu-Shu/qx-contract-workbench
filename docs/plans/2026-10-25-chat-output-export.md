# CH-08 对话成果复制与 Word 导出实施计划

**目标：**在 dhb_law 上贯通选定已保存成果 → 受众 → 预览 → 复制或 Word 下载。基线 4325711；既有未提交工作已独立保存在 .git/codex-preserved/ch08-20261025。

**架构：**只读投影现有不可变模型回答和档案修订，不新增数据库表或模型调用。模型回答仅内部；客户版仅白名单 client_reply 字段，内部版取该版本档案的明确字段。冲突候选拒绝猜选，人工保护值（包括明确清空）优先。输出身份绑定来源、版本、受众和投影摘要。后端每次预览/复制/下载核对当前身份、会话/案件权限及绑定；下载与复制必须匹配预览摘要。恢复副本阻断新的投影和导出，不修改旧备份格式。

**范围与文件：**领域 DTO 在 domain.py；assistant/outputs.py 负责授权投影和有界来源列表；exports/assistant_docx.py 只渲染投影；web/assistant_outputs.py 负责认证、CSRF、正文前后权限核对及下载；assistant-outputs.mjs 提供单一成果面板并接入现有工具栏。

- [x] 后端测试先行：客户信息隔离、人工清空/冲突、固定历史版本、来源与摘要错配、跨会话/当前绑定、撤权、恢复隔离；用独立虚构工作区，不联网。
- [x] 实现模型回答及档案来源的有界列表、预览、复制正文和 Word 下载；不从 DOM 或客户端正文生成文件。
- [x] 前端测试先行：选择受众后重新预览，切换/关闭清除正文，晚返回丢弃，动作前重新验证，剪贴板失败保留可手动选取的预览。
- [x] 实现成果面板、入口和下载；复用现有侧栏、字体和按钮风格，面板互斥，窄屏可读。
- [x] 定向 Python/Node 回归；实际本机 HTTP/浏览器跑客户版和内部版、复制/下载并检查 Word 包全部 XML 不含内部哨兵；渲染并目视检查样本。
- [x] 独立审阅后修复确认问题；更新任务状态和实际验证证据。既有改动不擅自提交，未验证的 Windows/生产/法律质量边界保持开放。

**验收：**有可操作入口；无客户回复时明确提示去档案填写；客户文件及剪贴板内容没有内部字段/成本/隐藏元数据；模型内部回答不能改受众导出；同一来源版本及摘要可重复读取；任何当前权限失败都不返回正文或文件；页面切换后旧响应不写入新会话；导出失败不重跑模型。
