DeepSeek Harness 仅作工作区组织参考：导航、会话与任务、原文预览、执行状态和设置。其官方桌面 README 描述 Electron 外壳及受限 preload/IPC，参考时保留权限边界，不直接复制完整运行体系。[桌面来源](https://github.com/deepseek-ai/deepseek-harness/blob/master/apps/desktop/README.md)；[前端来源](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/client/README.md)。

Impeccable 主导业务工作界面，采用 Operate 原则：中文长文可读、层级与操作一致、键盘可达、状态和错误可理解。Taste 辅助欢迎页、作品展示及适用的视觉细节；工作台保留信息密度、系统中文字体、低动效和明确分隔，不因展示规则加入远程字体、装饰图片或动画依赖。当前只确定职责，未替换现有界面。

首选验证 Electron＋现有 Python 引擎，Tauri 2 保留备选。先承载既有合同页面，新增公共工作区时再评估 React＋TypeScript；不把前端迁移设为首个桌面验证的前置条件。分别验证桌面进程、业务进程和数据目录；合同和持衡继续使用独立 Python 环境。

桌面仍加载受保护的同源页面，不能关闭现有 `same_origin`、登录、CSRF、案件授权或批准检查。源码已有 `frame-ancestors 'none'`，不能靠 iframe 嵌入并删除安全头解决整合。先评估同源路由或受控窗口导航；新 IPC 仅暴露必要操作，网页不能直接取得文件系统或任意 shell 能力。

## 页面和操作规则

左侧导航为获案与接待、内容创作、案件办理、合同审查、庭审辅助、个人知识。首页显示待跟进咨询、待核对材料、近期案件和执行中任务。中间为业务操作，右侧按需打开具体版本的原件与依据。

客户回复、律师内部意见、公开创作稿分别显示、复制和导出。意见点击后定位具体材料版本及位置，旁边直接显示待核验状态。切换案件时同时切换材料、会话、任务和预览，取消或隔离旧请求，防止迟到响应污染新案件。

正文允许调整字号；面板可收起和调整宽度。状态覆盖加载、空结果、无权限、超时、部分完成、失败和旧版本失效。模拟发言、当事人主张、已核实事实分别保存；模拟结果不回写为事实。

## 法律数据和仓颉

用户明确首批地方法规范围为吉林省。原始数据仍在 `F:\裁判文书网数据库\2025`，13个 CSV，16,452,507,459字节。本机既有 `D:\Documents\裁判文书数据库试点2025\data\judgments.duckdb` 本轮只读统计为10,000条来源记录，其中吉林省字段命中86条；408条文书类型为字面字符串 `None`，仍待语义清洗。本轮没有重导、扩容或全量向量化。历史逐字节回查和中断恢复证据继续使用，不改称本轮重跑。

分四层接续：原始资料、检索数据库、案件与规则整理、办案方法。原始 CSV、原始字段和字节位置保留；检索结果通过来源记录、文书及版本标识回到原文。案件整理保存法院认定、裁判理由、主张和争点的各自出处。仓颉仅为方法提炼与打包候选，不替代原文库、历史法规或律师审核。

方法卡接入必须关联来源版本、原文位置、原文摘要、适用条件、反例和审核记录。法规更新保留旧版，沿依赖关系使相关方法卡进入重新核验状态；技术评测通过不能升级为法律已核验。索引单独存储，在影子位置构建和核验后切换；不得把仓颉 `build_index.py` 指向原文库。该脚本现有全文件读取、删除重建和全局邻接扩展需隔离或适配。[研究记录](../research/2026-10-14-cangjie-legal-methods.md)。

吉林来源优先使用省人大法规规章规范性文件数据库、省政府公报，并按案件补充相关制定机关来源。本轮两公开入口均由本机 Scrapling 取得 HTTP200并记录 URL、UTC 时间、内容 SHA256，仍为未核验入口快照。人大样例页的施行/公布日期及效力正文未在静态提取中完整给出，须继续读取附件和历史版本，不能据 HTTP200认定现行有效或完整入库。[人大样例入口](https://www.jlrd.gov.cn/jlsjk/202311/t20231102_8827369.html)；[政府公报样例入口](https://www.jl.gov.cn/gb/2022/zb_202201/)。

先复用持衡既有法库接口；检索返回保留原始回执、来源快照、版本、定位和审核状态。空结果、访问受限、超时、来源未核验分别呈现。暂不增加第二套通用搜索平台，也不把WorkBuddy普通联网能力当作商业法律连接器已接通。
