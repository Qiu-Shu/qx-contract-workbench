# CH-07A：自动档案纯合并内核

基线 `a6d20edf8663222ce6469bae80edfc92c02627b2`，2026-10-23。接续已批准 v2.1 与 [设计复核](2026-10-23-profile-draft-readiness.md)。本片认领 CH-07A；不是整个自动建档完成。

## 实施边界

- DTO 追加在 domain.py；assistant/profiles.py 一个纯合并入口，复用 IntakeDraft、Anchor、ParseResult、精确 Decimal 和 UTC。无数据库、网络、时间获取、随机 ID、身份索引或真实模型调用；不接 HTTP/UI。
- 严格模型提案与独立受信人工编辑类型。逐项固定消息位置/摘要、文档原件/解析版本/锚点；给定源快照只能证明定位，当前权限留待提交服务重核。
- 未提供、unknown、人工清空分别表达；同值合并出处，异值并列；本金/利息/付款分字段。保护人工更正与旧接待（包括空字段），不自动升级核验状态。
- 接待投影只接受明确的受信开关；复用原字段限制、受众隔离与状态，不创造正式案件/客户。冲突不选择某一方；材料不自动 checked，超限拒绝。
- 版本严格匹配；相同输入确定性返回，相同语义提案按当前 base revision 重放不制造新修订。请求级回执重放在 CH-07B 事务中实施。

## 已授权验证 seam 与步骤

1. `merge_profile` 公共入口：先保留失败测试，再逐片实现消息/文档出处、合并、人工保护、投影；只用合成材料。
2. 同入口覆盖伪造 model_copy、错作用域/版本/摘要/位置、unknown、清空、冲突金额、幂等与边界；独立解释器验证不加载 Web/数据库/文档处理。
3. 目标回归复用 domain/schema、接待与助手来源相关测试；四开发门；记录稳定输入和实际计数，不重复桌面/安装测试。
4. Spec/Standards 独立复核，关闭实际发现。更新 README/TODO/TASK_STATUS 和合成证据；获取远端、检查改动后正常提交推送并核对 SHA/树。

## 后续闭环

CH-07B 才会在同一事务/savepoint 保存档案修订、已有接待投影、回执和事件，并同步迁移、备份、恢复与当前权限/版本检查。CH-07C 才接主模型结构化输出及固定钩子，复用同一次获准调用，不暗增付费抽取。人工保护不等于事实核实；未参与本片的安装版、真实法库/模型和云保持原状态。

## 独立复核后的明确收窄

- 本片模型提案中的 contact 只能是 unknown；已知联系方式只接受受信人工编辑。自动本地识别尚未接入，不能把“有一条来源”当作模型可猜测电话或身份的许可。
- 金额只接受有限精确值，最多16位整数、8位小数；根据 Decimal 原始数字/指数检查，不依赖调用方精度；零先规范化，避免极端指数放大字符串。
- 派生核验状态必须与候选和保护值一致；历史引用也受原对话及历史版本上限约束。旧来源无需仍在本次选片中；完整历史内容与当前权限分别由后续持久化/读取服务核验。
- 不同来源的相同文本保留各自位置；同名联系人不产生身份索引或跨事项合并。本片无主体识别或真实客户关联接口。
