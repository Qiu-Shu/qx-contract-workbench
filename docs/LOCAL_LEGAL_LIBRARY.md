# 本地法律资料库使用与恢复

本页描述已实现的操作；实际覆盖数量、速度和全量验收以同目录testing中的最新记录及页面“当前可检索”数字为准。资料清洗和来源字节校验不代表官方出处、法律效力或案件适用已经审核。

## 从工作台进入

在项目目录双击`启动法律资料库.cmd`，然后打开`http://127.0.0.1:8767/login`，继续使用原有登录账户。此入口沿用现有合同工作台并指定本机资料库位置`D:\Documents\群兴法律资料库`，不会创建另一个产品或重置账户。资料库与案件材料目录独立。等价命令在`D:\Documents\ChatGPT\律所项目`执行：

```powershell
.venv\Scripts\python.exe -m cn_contract.web.local_server start --library-directory 'D:\Documents\群兴法律资料库'
```

已有服务运行时不会自动更换其参数，应先在原工作台窗口按Ctrl+C，等待正在执行的任务结束，再启动本入口。重复启动会因工作区占用或端口占用而失败。不要删除账户目录、关闭登录或关闭同源核对来接入资料库。启动后点击“法律资料库”：左侧输入关键词或案号等条件，中间选择结果，右侧核对原文和来源。原文、版本及命中位置一起导出为JSON。字号可调，窄窗口会把原文区域移到结果下方。当前只是沿用源码环境的Windows启动入口，尚未生成独立安装包。

默认多词检索要求各词同时满足；空格分词。精确短语模式要求原文规范化后连续出现。支持“离婚”“租赁”等两字词；纯单字和运算符不会当成查询语法执行。规范化后的查询最多200字。过滤法院、案由、地域、文书类型时使用完整字段值；裁判日期仅适用于案例。文件名日期不是法规生效日。

填写精确案号并检索正文时，先限定该案候选，再优先展示标题命中词更多的资料，同分按稳定标识排列。此类案内排序不受无关案件新增数量影响；不带案号的全文检索仍使用全库相关度排序。

标题结果每法规版本只列一次，正文命中按原文位置展示。目录与引述候选直接标识，不能当成已经确认的条文。历史版本和待核验资料保留；未知效力不自动排除。达到查询时限或已浏览2000个候选时会要求缩小条件，这不表示后续没有资料。

## 命令行核对

```powershell
.venv\Scripts\python.exe -m cn_contract.library search --library-root 'D:\Documents\群兴法律资料库' --query '租赁'
.venv\Scripts\python.exe -m cn_contract.library verify --library-root 'D:\Documents\群兴法律资料库'
```

`show`按检索返回的record-id和version-id读取原文。参数详情可在对应命令后加`--help`查看。CLI与页面使用同一检索和原文校验逻辑，不联网、不调用模型。

## 导入和索引分开执行

法规原件在`F:\裁判文书网数据库\全量法律\全量法律`，2025案例原件在`F:\裁判文书网数据库\2025`。首次导入保留内容摘要快照；原件不改。重复导入核验已登记字节和版本，不会覆盖同案号的其他文书。同名法规不同内容分别保留，相同内容的来源别名保留。

```powershell
.venv\Scripts\python.exe -m cn_contract.library import-laws --library-root 'D:\Documents\群兴法律资料库' --input 'F:\裁判文书网数据库\全量法律\全量法律' --batch-id laws-local-20261014
.venv\Scripts\python.exe -m cn_contract.library build-index --library-root 'D:\Documents\群兴法律资料库' --activate
```

案例逐个CSV执行`import-cases`，沿用批次`cases-2025`。`--limit`是该文件累计导入的逻辑记录上限，不是本次新增数量；不传则继续至文件结束。旧试点的10,000条只读接续，旧标识保存在映射中。后续完整导入仍从各文件首条对账，因为试点可能是非连续抽样。

导入完成尚不等于页面可检索：只有建成并核验的新索引代际被激活后，页面才显示新增覆盖数。建索引失败或中断时保留旧代际。使用`build-index --resume 待完成代际ID`续建，来源目录变化时会拒绝续用旧指纹，此时应新建代际。已发布代际不能原地续写。

## 中断、备份和迁移

同时只运行一个资料库写入任务。案例按批次、法规按文件批次提交；已提交检查点保留。来源变化、损坏记录、磁盘预算和内存预算都会明确报错或记录失败，不能把未处理部分算作完成。当前软预算为进程8GiB、派生物200GiB、磁盘至少40GiB空闲；这些是定期检查，不是操作系统强制配额。

手动备份时先停止工作台服务和所有资料库导入、索引及审核进程，确认没有进程再打开该资料库，然后复制整个资料库目录，包括assets、catalog.sqlite及其仍存在的WAL文件、generations和current.json。不要在运行中直接复制数据库，也不要只复制检索数据库。复制结束在新位置运行`verify`，核对资产摘要与当前代际，并实际查询、打开已知原文；未核对前保留原目录。现有虚构恢复测试覆盖中文含空格路径和索引切换，真实全量恢复进度见验收记录；不能以测试代替每次实际备份核验。

`export-manifest`输出相对资产、记录数量、版本和摘要清单，**不是完整备份**；它不携带原件内容。导出使用新文件名，避免覆盖旧清单。原路径别名可能含本机目录信息，实际目录备份不能直接当作公开下载包。

阿里云后续通过认证HTTPS接口提供检索和原文读取，不让客户端直接挂载数据库。当前没有创建云资源或上传资料。1985—2024年仍待从用户百度网盘取得后逐批核验格式。法规官方出处、历史效力、方法卡审核及云端共享范围需要分别补核。
