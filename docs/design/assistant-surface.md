# 对话首页表面说明

模式：Operate。目标用户为中文 Windows 环境中的律师；先写下事情，再按需进入已有工作区。本页采用已批准的 `docs/plans/chat-first-architecture-v2.1.md` 第 4 节，执行范围见 `docs/plans/2026-10-17-assistant-home-drafts.md`。

画布 #F7F8FA、白色输入面、正文 #20252B、次要文字 #59636F、强调 #245BD7、边界 #DCE1E7。系统中文字体。左栏 232px，窄窗口收为 64px 或菜单；内容宽度最多 840px，输入区 112–240px，正文提供 16/18/20px。四张技能卡为用户指定的固定操作入口，没有营销图、动画或外部字体。

首片实际可用内容为本机草稿和已有历史、任务状态。发送与附件按钮明确禁用，原因在同页可展开；不展示虚构回复、读取进度、档案或任务。能力选择不等于执行。冲突保留本机输入，另列服务器文字供用户明确选择。

交互使用原生按钮、文本域、选择器、details 与焦点轮廓。错误、只读及保存状态均以文字表达。模板只含空/加载状态，不嵌入案件正文。模板与样式完成不代表真实浏览器、Windows DPI、物理中文输入法或完整聊天功能已验收；本阶段实测结果另记在阶段测试证据中。
