# 法律方法参考来源

本片群兴方法参考 Anthropic 的 [claude-for-legal](https://github.com/anthropics/claude-for-legal) 及陈石律师（CSlawyer1985）的[中国法适配版本](https://github.com/CSlawyer1985/claude-for-legal-ZH)，作者署名依据原包 README 保留。英文原包固定提交为 `4a6c651889c97cc9140580363c73e0eb17379c2b`；本片直接阅读的中文文件固定提交为 `171903c9e5e91b3b7625f1dd557d146ba5a25adc`，逐文件摘要见同目录 `contract-method-sources.json`。

两个原包均为 Apache-2.0，本目录 `LICENSE` 原样保留已审计中文包的许可文本。群兴只重写吸收合同分流、保密范围、供应商逐项分析方法，不安装上游运行框架、操作脚本、发送流程或静态法律断言。运行方法有独立版本和 SHA-256；这些证据不表示法律质量、生产打包或发布已获批准。

原包和全部文件的只读审计、出处比对及 SHA-256 清单位于本机桌面 `群兴法律Skill只读审计_20261101_01a19764/`。不将本机审计临时目录作为运行依赖。

刑事案件分析与辩护策略的四份已读来源和摘要见 `criminal-method-sources.json`。本片采用群兴重写的证据分类、要件及策略候选方法；上游模板、配置指令和静态法条仅用于审计，不进入运行提示。当前仅允许合成材料及本机模拟模型，未确认真实案卷脱敏政策，也不表示已接入刑事模拟庭审。

商标侵权因素初筛的三份审阅来源和摘要见 `trademark-method-sources.json`。本片仅吸收因素清单及双方证据并列的方法，不作侵权认定，不安装其他知识产权分支、警告函或发送流程。上游 company-profile.md 运行配置未提供，未继承任何默认身份、管辖、审批或保密特权；静态法律未经本轮核验，不作为现行法依据。开发使用合成材料，本片不构成真实案件或法律质量验收。
